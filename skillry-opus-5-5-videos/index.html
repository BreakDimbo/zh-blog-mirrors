如何使用提示词

  1. 打开一个提示词文件，复制 Prompt 下面的代码块。
  2. 把它粘贴给 Claude Opus 5.5（Claude Code、Claude 应用，或任何跑 Opus 5.5 的智能体）。
  3. 让它把结果渲染成一个 HTML 文件；想要视频的话，再把页面录下来。

有些创作者只分享了部分提示词，或者只在帖子里描述了效果；这些文件里会注明。

数据速览与六个规律

维度数字
Skillry 画廊作品418 支（动态图形 229 · 解说 68 · 3D 场景 56 · 游戏与交互 65）

技术标签（Skillry 重制版用到的）Canvas 267 · SVG 183 · Three.js 131 · GLSL 92 · GSAP 86 · CSS 57 · Web Audio 39
文本中提到的工具链Remotion 84 次 · HyperFrames 24 次 · Python（多用于合成音乐）15 次 · ElevenLabs / Gemini TTS 若干
  1. “showreel 母题”是最大的流量来源。一句“make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are… go all out”被换上几十个不同的品牌反复用（“go all out”出现 31 次，“motion designer”出现 37 次）。让模型“为自己的作品集而做”，似乎能把它的审美上限逼出来。
  2. 结构化模板开始流行。@twoclipping 的“一个形状变成 8–12 个 UI 状态”模板，开头用 <inputs> 让模型先向你要素材，再用 <rules> 规定一镜到底和单一强调色，至少有 9 位作者原样或改写后在用。@op7418 的中文“手游高光时刻”模板用【世界观与风格】分节，也是同一个思路。
  3. 音画都用代码做。大量作品强调“每一帧、每个声音都是代码”：画面用 Remotion 或 HyperFrames，音乐用 Python 从正弦波和噪声合成，再按节拍把剪辑和音效对齐。好的作品还会给 BPM，或者分析节拍、在落地和盖章的瞬间放音效。
  4. “看不见的内部”成了解说片的爆款结构。@aichrislee 的镜头、心脏、手表，还有涡扇、猛禽发动机、聚变堆，都是同一个骨架：外观逼真 → 列出内部零件 → 剖开 → 演示物理过程 → 可拖拽缩放加 Explode 按钮。
  5. 尺度跃迁一镜到底。从桌面推到硅原子、从手机推到原子、从罗卡角拉到可观测宇宙、未来三十年五站飞行……连续的镜头加上尺度变化，3D 题材最容易出爆款。
  6. “一句提示词一次成片”有夸大成分。认真的作品（手表品牌片、Synclify、Claude Pop MV）都写明了“先出分镜，每拍一张静帧，再多轮批注”；也有作者直说“这次要推回好几轮”。建专门的 studio 仓库、导出联系表审片、让模型自己导出静帧检查文字有没有截断，才是稳定出片的办法。

对我们的启发

  1. 把审美写成数字。最好的提示词（@heyiamnick 的铅笔线 showreel、@humzaakhalid 的品牌片）都会写死字体字重、色值、字距、帧率和时长，和 Opus 5.5 动效实验室里讲的“把形容词换成数字”是同一个原则。我们自己写视频提示词，也应该先写一页参数规格。
  2. 做模板，别做一次性的提示词。母题和 <inputs> 模板之所以传播得广，是因为换个品牌就能复用。可以把常用片型（产品发布片、看不见的内部、尺度跃迁、配方/流程动画）各写成一个带占位符的模板，或者做成 skill，就像 Motion Prompt 动效库做的那样。
  3. 声音和画面一样重要。不少作品是靠“每刀都卡在拍子上”出彩的，也有不少作者坦言自己的短板在音效。可以搭配 Openverse 免费音效检索，或者固定一套“Python 合成 + 节拍对齐”的流程。
  4. 要设置验证循环。让智能体导出静帧和联系表来自查，按分镜 → 静帧 → 动画分阶段确认，必要时让它先分析“优秀案例比我好在哪”。这比单纯堆“go all out”可靠得多。
  5. 真实素材加代码包装。Lemo-Opuscar 实证影像用的是真实素材，本合集里则有游戏真实回放、真实 UI 截图、真实点火顺序和真实数据。代码负责包装，真实素材负责可信度，这是避开“AI 味”最有效的办法。
