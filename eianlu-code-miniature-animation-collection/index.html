三、提示词照录

3.1 孟菲斯微缩世界（Eian，10-26 20:29，原文）

用代码做一支 20 秒的"孟菲斯微缩世界"小动画，1080×1080，60fps。
画面：把一个场景做成会动的微缩模型。暖白底，内容放在居中的圆角画框里，四周多留白；画框边缘是颗粒状消散的边（像喷漆），开场从中心颗粒状长出来，结尾收回去。
配色：孟菲斯风格。饱和原色 + 粉彩（黄 #FFC93C、粉 #FF8DB5、钴蓝 #2E5BE6、珊瑚红 #FF5A5F、薄荷绿 #A9E6C6、天蓝 #8DD3F6、淡紫 #D3BEFF），所有物体有深靛色 #25214A 描边和不模糊的硬投影，大色块上铺圆点、条纹、折线这类小图案。
镜头：一镜到底，缓慢匀速移动，可以带一点旋转和推近。
节奏：靠画面里的小动静撑起来，比如鸟飞过、云影掠过、鱼游、人走、车开、叶子飘落，至少安排一两个有"剧情"的瞬间。
文字：画框下方三行居中小字：标题（中英）/ 季节 · 一句描述（中英）/ 随镜头变化的经纬度。
做法：用 Canvas 写一个确定性的 frame(i) 函数，输入帧号输出一张图，场景按坐标和固定随机种子生成；用无头 Chrome 逐帧导出，ffmpeg 合成。配乐也用代码合成：五声音阶的轻旋律 + 环境声，画面里的事件要和音效卡上。

四、技术细节：作者明说 vs 本站推断

作者明说（来自原帖与回复）

  • 模型：Opus 5.5（回复“是的”）；做法是直接提示词，没有用 skill。
  • 管线：Canvas 写确定性 frame(i)，场景按坐标 + 固定随机种子生成；无头 Chrome 逐帧导出；ffmpeg 合成。
  • 规格：20 s、1080×1080、60 fps；一镜到底、缓慢匀速，可带旋转和推近。
  • 镜头视角可调：“不一定非要俯视”。三支成片分别是俯视、等轴测和剖面。
  • 画面：暖白底、居中圆角画框、喷漆颗粒边，开场从中心长出、结尾收回。
  • 色板 7 色，加 #25214A 描边与不模糊的硬投影；大色块上铺圆点 / 条纹 / 折线。
  • 节奏：鸟、云影、鱼、人、车、落叶等小动静，至少一两个“剧情瞬间”（前一帖举例：鸟飞、鱼动、青蛙跳水）。
  • 字幕三行：标题（中英）/ 季节 · 描述（中英）/ 随镜头变化的经纬度。
  • 声音：代码合成五声音阶旋律 + 环境声，事件卡音效。但作者也说“其实是可以的 不过没有自己找音乐好”。
  • 流程：先看 4 张样帧拼图再渲全片；认可样帧里应包含开场和收尾。
  • 也可以做成网页动画，可以交互。

本站推断（作者未说，复刻时补上）

  • 帧内时间用 t = i / fps 计算，合成时 ffmpeg 再用 -framerate 指定帧率。这是评论区 @zealdin 的建议，作者没有否认。
  • 种子 PRNG 只在构建场景时调用；frame(i) 不保留帧间状态，这样才能跳帧导出样帧，并与全片同号帧一致。
  • 画框“颗粒边”是一组固定种子的粒子：开场时沿增长圆分布，稳定后沿画框分布。成片封面帧里这条边很宽、圆角很小，看起来更像雾化噪点带。
  • “硬投影”的画法：同一路径偏移几个像素，先用深靛色填充，再画本体；不用 shadowBlur。
  • 画面事件与音效共用一份节拍表（cue sheet），不手抄时间。
  • 用 canvas.toDataURL 导出 PNG，而不是截屏；1200 帧 PNG 要预留约 400 MB 临时磁盘。
  • 暖白底色值、画框尺寸、线宽、投影偏移、字体：作者都没给，AGENT.md 里给的是可改的默认值。

六、Agent 复刻包

下载：AGENT.md：自包含的任务书，可以直接交给 Claude、Codex 或其他 coding agent。参考实现源码：frame.js · cues.js · index.html · export.mjs · music.mjs · package.json

AGENT.md 的内容：作者原提示词与场景槽；孟菲斯风格变量表，每项标注【作者】或【推断】；文件结构；确定性 frame(i) 契约；无头 Chrome 导出脚本；代码配乐；ffmpeg 命令与检查；执行流程；QA 清单；未知项。

复刻要点（摘要）

  1. 一份节拍表（cues.js）：写明 fps、时长、种子、字幕和事件时间，画面与声音都从这里读取。
  2. frame(i) 是纯函数：t=i/fps；种子 PRNG 只在构图时调用；不用 Date、Math.random、rAF 或 CSS 动画。
  3. 无头 Chrome：用 puppeteer-core 调系统 Chrome，逐帧执行 frame(i) 后用 toDataURL 存 PNG；先用 --only= 出 4 张样帧，拼成 2×2 等人确认。
  4. 代码配乐：五声音阶拨弦，加低通噪声做的水声，再按节拍表放鸟叫、蛙鸣、落水声；音量包络跟随颗粒进出场。
  5. ffmpeg：-framerate 60 -i frames/%05d.png -i audio.wav -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest -movflags +faststart。
  6. QA：帧数与时长准确；无黑帧；没有色板外的颜色；投影统一且不模糊；事件与音效偏差不超过 1 帧；字幕不被颗粒边吃掉；同一帧导出两次 md5 一致。
