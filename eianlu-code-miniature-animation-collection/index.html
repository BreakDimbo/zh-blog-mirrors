一、作品总览

六支片子的共同点：画面全部由代码生成（作者原话“画面全部由 Claude 写代码渲染完成”“视频由代码生成”）；主题都是“家乡”或地方；都有明确的数据或坐标锚点（城市建筑数据、卫星影像、经纬度字幕）。不同点在于工具链：《一座城的年轮》用了开源 skill lemo-opuscar，孟菲斯系列作者明确说是“直接提示词”，没有用 skill。

3.1 孟菲斯微缩世界（Eian，10-26 20:29，原文）

用代码做一支 20 秒的"孟菲斯微缩世界"小动画，1080×1080，60fps。
画面：把一个场景做成会动的微缩模型。暖白底，内容放在居中的圆角画框里，四周多留白；画框边缘是颗粒状消散的边（像喷漆），开场从中心颗粒状长出来，结尾收回去。
配色：孟菲斯风格。饱和原色 + 粉彩（黄 #FFC93C、粉 #FF8DB5、钴蓝 #2E5BE6、珊瑚红 #FF5A5F、薄荷绿 #A9E6C6、天蓝 #8DD3F6、淡紫 #D3BEFF），所有物体有深靛色 #25214A 描边和不模糊的硬投影，大色块上铺圆点、条纹、折线这类小图案。
镜头：一镜到底，缓慢匀速移动，可以带一点旋转和推近。
节奏：靠画面里的小动静撑起来，比如鸟飞过、云影掠过、鱼游、人走、车开、叶子飘落，至少安排一两个有"剧情"的瞬间。
文字：画框下方三行居中小字：标题（中英）/ 季节 · 一句描述（中英）/ 随镜头变化的经纬度。
做法：用 Canvas 写一个确定性的 frame(i) 函数，输入帧号输出一张图，场景按坐标和固定随机种子生成；用无头 Chrome 逐帧导出，ffmpeg 合成。配乐也用代码合成：五声音阶的轻旋律 + 环境声，画面里的事件要和音效卡上。
先给我看 4 张样帧拼图，我确认后再渲全片。

  • 管线：Canvas 写确定性 frame(i)，场景按坐标 + 固定随机种子生成；无头 Chrome 逐帧导出；ffmpeg 合成。
  • 规格：20 s、1080×1080、60 fps；一镜到底、缓慢匀速、可带旋转和推近；镜头视角可调（不一定俯视）。
  • 色板 7 色 + #25214A 描边与硬投影；大色块铺圆点 / 条纹 / 折线。
  • 字幕三行：标题（中英）/ 季节 · 描述（中英）/ 随镜头变化的经纬度。
  • 声音：代码合成五声音阶旋律 + 环境声，事件卡音效；但“没有自己找音乐好”。年轮片配音用豆包语音大模型 2.0（火山引擎 API Key 交给 Codex / Claude 调用）。
  • 流程：先看 4 张样帧拼图再渲全片；认可样帧应包含开场与收尾。
  • 卫星片：NASA/USGS 公开影像，让 AI 去找；约 7 GB 原始素材；同轨道 ±1–2 年逐像素去云合成；城区上空单独打雾霾分。
  • 也可以做成网页动画、可交互。

本站推断（作者未说，复刻时补上）

  • 时间用 t = i / fps，合成时 ffmpeg 用 -framerate 指定（评论区 @zealdin 的建议，作者未否认）。
  • 种子 PRNG 只在构建场景时调用；frame(i) 不带帧间状态，才能跳帧导出样帧且与全片同号帧一致。
  • 画框“颗粒边”= 一组固定种子的粒子，开场沿增长圆分布、稳定后沿画框分布。成片封面帧里边缘很宽、圆角很小，更像雾化噪点带。
  • “硬投影”= 同一路径偏移数像素、用深靛色先填，再画本体；不用 shadowBlur。
  • 画面事件与音效共用一份节拍表（cue sheet），避免手抄时间。
  • 导出时用 canvas.toDataURL 取 PNG，而不是截屏；1200 帧 PNG 需预留约 400 MB 临时盘。
  • 暖白底色值、画框尺寸、线宽、投影偏移、字体：作者均未给，AGENT.md 里给的是可改的默认值。

复刻要点（摘要）

  1. 一份节拍表（cues.js）：fps、时长、种子、字幕、事件时间。画面与声音都从它读取。
  2. frame(i) 是纯函数：t=i/fps；种子 PRNG 只在构图时调用；禁用 Date、Math.random、rAF 和 CSS 动画。
  3. 无头 Chrome：puppeteer-core + 系统 Chrome，逐帧 frame(i) 后用 toDataURL 落盘 PNG；--only= 出 4 张样帧，先拼 2×2 等人确认。
  4. 代码配乐：五声音阶拨弦 + 低通噪声水声 + 按节拍表放置的鸟叫、蛙鸣、落水声，包络跟随颗粒进出场。
  5. ffmpeg：-framerate 60 -i frames/%05d.png -i audio.wav -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest -movflags +faststart。
  6. QA：帧数和时长准确、无黑帧、无色板外颜色、投影统一且无模糊、事件与音效偏差不超过 1 帧、字幕不被颗粒边吃掉、同一帧两次导出 md5 一致。
