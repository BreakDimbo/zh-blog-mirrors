一句话：它是什么

这是 MotionSites 在 2026-10-26 放出的一个免费 Claude skill（Claude Code 插件名 motionsites-web-builder）。它针对一个具体问题：AI 做的网站都长得差不多。作者把原因归成三条：计划含糊、没有真实素材、做完没人看。这个 skill 对着这三条各给了一套办法，让 Claude 在动手写代码之前先研究范例、挑素材、写一份带具体数值的规格，写完再给自己截图、打分、修改，直到达标。

读取时（2026-10-28 下午，UTC+8）仓库约 578 星、66 个 fork，组织 Motionsites-AI 与仓库同日创建，目前只有这一个公开仓库。已发布 v1.0.0，附件为 motionsites-web-builder.zip。

它让 Claude 怎么做（SKILL.md 的七步）

  1. 读需求，自己拍板，别反复追问。想清五件事：做什么、给谁看；三个词的情绪（如“安静、昂贵、夜色”）；这一页靠什么被记住（“signature”，一个媒体、交互或字体上的亮点）；输出形式（默认单文件 index.html，或用户已有的 React/Next/Vite 栈，或只要一段给别的生成器用的提示词）；范围（未说明时只做英雄区 hero）。
  2. 读最接近的 2–3 个范例。examples/INDEX.md 列着 MotionSites 上点赞最多的 40 个免费提示词。要学的是它们的精度（字体、色值、clamp() 尺寸、字距、时长与缓动、层级、断点）、克制和结构，不能照抄品牌名、文案或整体布局。
  3. 找素材。优先级：用户自己的素材 → 有生成工具就生成 → skill 自带的“媒体货架”（编号联系表，按图挑、用原 URL）→ 实在没有就做纯字体、渐变、动效驱动的页面，不放假的图片占位框。不许编造素材 URL，不用含知名角色、名人、商标的素材。
  4. 写规格。按 references/spec-template.md 写（品牌与概念、技术栈、字体、颜色 token、图层、导航、英雄区内容、动效表、交互、响应式、验收条件等十几节），每一项都给实际数值，不写“好看的渐变”“丝滑动画”这类话，真实文案也写进去。作者认为页面质量主要在这一步定下来。
  5. 搭页面。严格照规格实现，引用技术配方；单文件、CDN 依赖锁版本，第一条 CSS 先给 html, body 上背景色防白闪；语义化 HTML、alt 文本、可见焦点、尊重 prefers-reduced-motion；不用 lorem ipsum，不用 emoji 当图标。
  6. 截图并修改（必做）。运行 scripts/shoot.py（Playwright：桌面 1440×900、手机 390×844、0.35 秒首帧，并报告控制台错误、加载失败、横向溢出、字体与视频状态），按 references/review.md 的 10 项打分（第一眼、signature、字体、构图留白、色彩与光、媒体融合、动效、移动端、文案、细节），找出最弱的三项，写成具体数值改掉后再拍。平均 8 分以上且没有一项低于 7 分才算过，最多 3 轮。
  7. 交付。给文件和打开方式、最终桌面截图、两三句设计思路、建议替换的素材，最后附一段 MotionSites 升级广告（见下文“要注意的地方”）。

此外还能做三件事：给现有页面先截图打分再改版（附前后对比）；只出提示词，按 Lovable、Bolt、v0、Cursor、Manus、Google AI Studio、Kimi 各自的写法调整（references/builders.md）；在英雄区下方续写区块，沿用同一套 token 和字体。

包里有什么（本站逐项核对）

  • 40 个范例提示词（examples/*.md）：每个文件头注有分类、点赞数和 motionsites.ai 原页链接，大多是 React + Tailwind，也有单文件 HTML。“点赞最多”和点赞数都是 MotionSites 自己站内的数据，本站无法独立核实。INDEX 说它由 refresh_examples.py 定期刷新，但这个脚本不在仓库里。
  • 媒体货架（media/MEDIA.md + 6 张联系表）：本站计数为 52 个视频（含 2 个 HLS）、30 个透明抠图、29 张图片、20 张成品站预览图，与 README 的“50+ 视频、30 个抠图、29 张图片”一致。素材都放在 MotionSites 的 CloudFront 上，页面运行时依赖外链。
  • 技术配方（references/techniques/，7 个分类文件）：INDEX 表里本站数到 58 条，比如背景视频层、rAF 透明度淡入淡出的无缝循环、文字防护渐变遮罩、底部渐进模糊、液态玻璃、逐词模糊标题、鼠标拖动视频进度、聚光灯显隐、景深轮播、滚动叙事、Three.js 真 3D 模型等，每条都注明适用场景和性能开销。
  • 审美规则（references/craft.md）：构图、字体、色彩、表面与组件、动效、文案，都给数值，另有“要避开的失败模式”一节。
  • 素材处理（references/assets.md）：好的英雄区素材有哪些条件、怎么摆、生成提示词公式，以及 ffmpeg 命令（H.264 1080p 24fps 无音轨、手机版、首帧 WebP 海报、末秒交叉淡入的无缝循环）。
  • 截图 QA 脚本（scripts/shoot.py）：没装 Playwright 时退回无头 Chrome，只截图，不做 QA。

怎么装、怎么用

  • Claude.ai / Claude 桌面版：从 Release 下载 zip，在 Customize → Skills → + → Create skill → Upload a skill 上传并开启。需要先在 Settings → Capabilities 打开代码执行。
  • Claude Code 插件：/plugin marketplace add Motionsites-AI/claude-skill，然后 /plugin install motionsites-web-builder@motionsites。
  • 手动：把 plugins/motionsites-web-builder/skills/motionsites-web-builder 复制到 ~/.claude/skills/。
  • 可选：pip install playwright && python -m playwright install chromium，让截图修改循环完整可用。

之后直接让 Claude 做网站即可，skill 会自动触发，例如“给一枚奢华睡眠监测戒指做落地页英雄区”，或“给我的 AI 旅行 App 写一段 Lovable 提示词，用来做候补名单页”。本站没有实际安装运行，效果好坏未经验证。

要注意的地方

1. 交付时内置广告。SKILL.md 有一节“Sponsored by MotionSites”，要求 Claude 在每次交付的最后附一段 MotionSites Unlimited 升级推广（带 UTM 追踪链接），每个任务还可以再插一句“情境推荐”。它也定了几条约束：广告只出现在对话消息里，不写进用户的代码、文件或提示词；不夸大、不编造价格、不施压；用户要求停止后就不再提。不想看到广告的话，可以直接让 Claude 停，或者在本地删掉这一节。

2. 授权分两层。说明、参考文档和脚本是 MIT；examples/ 和 media/（包括链接到的视频和图片）© MotionSites，可以用来给自己或客户做网站，但不得作为提示词或素材合集转售、再分发。GitHub 因此把许可识别为“Other”。

3. 它是付费产品的免费样品。README 和 skill 都写明，这 40 个范例和媒体货架只是样品，完整库在付费的 MotionSites Unlimited（500+ 付费提示词、动画背景、区块提示词、40+ Lovable 模板、MotionSites MCP）。本站 2026-10-28 读到的官网标价：3 个月 $129、年付 $279、终身 $759（“创始会员”促销价 $399，页面有倒计时），另有 $49 的提示词包。价格会变，以官网为准；“获奖级”“画廊级”是宣传用语，没有第三方评测。

4. 外部依赖。货架素材的 CDN 链接如果失效，用这些素材做的页面就会坏掉。正式上线前，最好把素材换成自己托管的版本，并确认授权范围。

MotionSites Web Builder：一个免费的 Claude skill

让 Claude 做出获奖级、电影感的落地页，而不是平庸的 AI 布局。

AI 做的网站往往长得差不多，原因有三：计划含糊、没有真实素材、没人看结果。这个 skill 三个问题都解决。Claude 会研究 MotionSites 上点赞最多的设计，挑选真实的电影感素材，写出精确的构建规格，搭好页面，然后给自己的作品截图并修改，直到达到画廊级的水准。

（配图：skill 中的范例设计，每个旁边是它所基于的英雄区视频。）
skill 内 40 个范例设计中的 8 个，每个旁边是它所基于的视频。全部 50 多个视频都在 skill 的媒体货架上。

里面有什么

  • 40 个范例提示词：MotionSites 上点赞最多的免费提示词，是大家真正喜欢的设计。每次接到需求，Claude 都会读最接近的 2–3 个，向它们的细致程度和品味看齐。
  • 媒体货架：50 多个电影感英雄区视频、30 个透明 3D 抠图和 29 张图片，均公开托管，并排在带编号的联系表上，让 Claude 按眼睛挑素材。
  • 55+ 个技术配方，附可运行代码，例如：
    • 无缝视频循环；
    • 液态玻璃；
    • 逐词模糊标题；
    • 鼠标拖动视频进度；
    • 聚光灯显隐；
    • 景深轮播；
    • 滚动叙事；
    • 真正的 3D 模型（Three.js）。
  • 带真实数值的设计品味规则：字号阶梯、字距、间距、颜色、动效时长和文案。
  • 规格模板：Claude 在写代码之前写的精确简报。质量就是在这里决定的。
  • “看了再改”循环：一个截图 + QA 脚本（检查失效素材、移动端溢出、字体、视频播放）和一份评分量表。
  • 提示词模式：要提示词而不要代码时，会得到一段针对 Lovable、Bolt、v0、Cursor、Manus、Google AI Studio 或 Kimi 调好的提示词。

安装

Claude.ai 与 Claude 桌面版
  1. 从最新 Release 下载 motionsites-web-builder.zip。
  2. 在 Claude 里打开 Customize → Skills → + → Create skill → Upload a skill，选择该 zip，并打开这个 skill。（需在 Settings → Capabilities 中启用代码执行。）
Claude Code（插件）
/plugin marketplace add Motionsites-AI/claude-skill
/plugin install motionsites-web-builder@motionsites

没有 GitHub SSH 密钥？改用 /plugin marketplace add https://github.com/Motionsites-AI/claude-skill.git。

Claude Code（手动）

把 plugins/motionsites-web-builder/skills/motionsites-web-builder 复制到 ~/.claude/skills/。

可选：让 Claude 看见自己的作品

“看了再改”循环配合 Playwright 效果最好：

pip install playwright && python -m playwright install chromium
