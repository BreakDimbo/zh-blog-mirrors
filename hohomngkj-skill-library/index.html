导读

这是一条“自荐”推文：作者龚浩 Snail 本人就是这家工作室的主理人，个人简介写的是“用开源免费 ComfyUI 创作 AI 影像……提供创作资源、云端工作流部署与教学”。

推文推荐的网站有两块内容。一块是 Skill 风格库：把一种画面风格（光线、配色、材质、构图）拆成一个可安装的“Skill 包”，里面有参考图、视觉分析、“核心规则和可变规则”、提示词模板和偏差修正方法。思路是先把风格固定成规则，再换人物、服装和场景，批量出同风格的系列图。另一块是剧情短片开源分享：9 部 20 秒到 1 分钟的 AI 短片，每部附分镜和提示词。

样片谁都能看。但想拿到完整提示词和资源包，页面上写的是：“可添加微信咨询 Skill 开通方式”。所以“直接装就能用”有个前提，就是先开通。

要点

  • 93 套风格包，分 10 类：人物华服 20、情绪叙事 13、神话仙境 11、建筑空间 10、武侠江湖 9、古典雅居 8、科幻未来 8、梦境奇想 8、田园乡野 4、旷野西部 2。
  • 每套的结构基本一致：原始参考图 → 视觉分析 → 核心/可变规则 → 提示词模板 → 系列创作规则 → 偏差修正。列表页上多数风格卡片标着“4 张样片”，介绍里写的是 16:9 横版。
  • 有电影风格提炼，也有原创人像：有的名字直接写成“××式”，比如列表第 1 页的“马力克《生命之树》式·广角贴近与流动自然光”；更多是工作室原创的人像风格，比如“赭壁青巷·暖影肖像”“银帘烛影·玄白绣境”。
  • 短片板块：9 部剧情短片，每部 4–16 张分镜、6–36 条提示词。原话是“资料包含分镜与提示词，成片可在详情页下载”。
  • 需要开通：完整提示词和 ZIP 包要走微信开通或登录账号，卡片上的按钮就是“微信咨询开通”和“已有权限？登录账号”。

风格库里有什么

列表页每页 20 套、共 5 页。每张卡片标出分类、样片数、资源类型（第 1 页都是“Skill 安装包 ZIP”）和文件大小，下面是一段风格描述、几个标签和版本信息。完整内容要开通后才能看到，本文不涉及任何付费内容。

描述的写法很统一，都是“材质 + 光线 + 色彩 + 景深”。例如：“以赭米旧墙与青灰虚化街巷分隔冷暖空间，暖侧光穿过细发……”。有几套还写得比较老实，比如“风格由参考画面提炼，非原作者提示词；已在 ImageGen 试图，跨模型效果需另行验证”。

我们核实到的情况

“专为 ComfyUI 准备”：列表页第 1 页的风格介绍里没有提到 ComfyUI，有一套还写着“已在 ImageGen 试图”。更准确的说法是：这是一套“风格→提示词”的规则包，可以在 ComfyUI 里用，但我们在公开页面上没有看到 ComfyUI 工作流或节点。作者另有工作流栏目，本文没有展开。

“直接装就能用”：要先通过微信开通或登录。我们没有拿到任何资源包，所以“风格一致性很高”无法验证。

“开源短片”：页面写的是“开源分享”，但没有看到许可证。“开源”在这里的意思是公开制作资料，不是 OSI 意义上的开源许可。

版权提示：“××式 / ××启发”的风格提炼和经典片段重演，用在商业项目前请自行评估肖像、IP 和风格模仿的风险。

对我们的启发

  • “风格 = 规则包”是可以照搬的结构。参考图 → 视觉分析 → 核心/可变规则 → 模板 → 纠偏，比单条提示词好复用得多，和 OPUSCAR 98 种风格、Lemo-Opuscar 把电影风格写成提示词是同一种做法。区别是这里面向静帧人像，而且把“偏差修正”单独列成一步。
  • “核心规则 / 可变规则”的划分值得学。先写清楚哪些不能动（光线方向、色彩分区、材质反光），哪些可以换（人物、服装、动作、道具），系列图才能保持一致。Florence 动效实验室里“把形容词换成数字”的思路，也可以用在这里。
  • 描述写法本身就是一份提示词范式。“材质 + 光线 + 色彩分区 + 景深 + 样片动作名”，这种写法可以直接借来写自己的图像提示词。
  • 对推荐语要做核实。“专为 ComfyUI”“直接装”“开源”这三个词，到站点一看都要打折扣。我们收录资源站时，应当照 OpenNana 那篇的做法，写清楚哪些免费、哪些要付费，以及有没有许可证。
  • 短片“分镜 + 提示词 + 成片”三件套适合拿来学习 AI 短片制作，可以对照 H3 Director 工作流（ComfyUI 视频）、打斗冲击帧、3D 武侠 ARPG 看中式题材的不同做法。
