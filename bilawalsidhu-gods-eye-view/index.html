God's Eye View 是一个在浏览器里运行的开源三维地球。它把已经公开的飞行应答、船舶信标、轨道根数、地震、火灾、天气和公共摄像头等信号放在同一幅可探索的球面上，也可以用语音或文字向这个画面提问。外观像一间禁区里的操作舱，但源码可以检查，多数图层不必先申请密钥。

一、它是什么

仓库自述是 A spy-satellite simulator in your browser — then you realize the sources are public and the data is real. 前身叫 WorldView。维护者是 Bilawal Sidhu 与 Sameh Khamis，所属公司为 Halfpixel。官方站点是 godseyeview.ai。

它做的不是再做一个静态地图，而是把多层公开信号叠在 CesiumJS 地球上，并让你点选、跟踪、进入驾驶舱视角，或用语音在真实地形上画边界、量距离、切换传感器风格（CRT、夜视、FLIR 等）。默认在本机浏览器运行；也可以作为 MCP 服务器，让 Claude Desktop、Codex 或 ChatGPT 桌面版在对话里打开同一幅地球。

README 自己划了一条线：项目刻画的是事件、资产、基础设施和系统——飞机、船舶、卫星、火灾、摄像头、城市——不为检索具名个人、人脸识别或追踪个体做功能，这类拉取请求不会被合并。它也写明：这是探索与学习用的演进中开源客户端，不是加固过的生产服务；数据可能延迟、不完整、被建模或推断，不可用于航行、应急、医疗、投资或其他安全关键用途。

二、球上有什么，怎样工作

README 表列二十余个图层与底图来源，并称其中二十个有无需密钥的路径。无密钥时可先用 Esri 卫星影像和关键地形（Esri 不可达时回退到 OSM）。要看 Google 摄影级三维城市与世界地形，需符合条件的个人非商业 Cesium ion 令牌，或走计量的 Google Maps 密钥。语音和部分分析功能需要 OpenAI 或 Gemini 密钥。船舶（AISStream）、活火（NASA FIRMS）、交通流速（TomTom）、街景 Mapillary 等也有各自的免费或计量档。

  • 运动与轨道：OpenSky 与 adsb.lol 的民航与军用 ADS-B、AISStream 船舶、CelesTrak 约 1,300 个空间目标（含空间站、成像、电信、Starlink、探测器、碎片）、Launch Library 2 近 30 天发射回放（标明为重建估计）。
  • 事件与天气：USGS 地震、NASA FIRMS 活火、WFIGS/NIFC 火场周界、NOAA/ECMWF 风场、nowCOAST 雷达云图与闪电、NHC/CPHC 气旋路径。交通是在 OSM 道路上的模拟车流；有 TomTom 密钥时用实时流速上色，但单个车辆位置仍不是实地观测。
  • 摄像头与街道：多个城市交通摄像头被投影进三维空间，姿态是需用户校准的粗估计。另有 OSM 标注的车牌识别摄像头位置（只有位置和标签，没有车牌或视频），以及 Mapillary / KartaView / Panoramax / Google Street View 的街景面板。
  • 捆绑静态基础设施：数据中心、水坝、海底电缆。其中 TeleGeography 海缆为 CC BY-NC-SA 3.0，禁止按 MIT 做商业使用；水坝与数据中心来自 OSM / Open Infrastructure Map，适用 ODbL 1.0。

运动上，实时源大约每 15–30 秒更新一次，球体渲染会落后一个间隔并在已知点之间插值，空隙用航位推算补上。卫星用 SGP4 传播，轨道环按 GMST 对齐。图标朝向按真实航向做屏幕空间投影，不随相机胡乱旋转。界面是 Vue 3 与 Pinia，地球是 CesiumJS，构建用 Vite。密钥（除浏览器必须持有的 Google Maps 与 Cesium ion 外）走本机服务端代理。

三、怎么开始

本地运行不必先有账号或 API 密钥。README 给出四条路径：

  1. Pinokio：安装或更新到 8.2 或更新版本，在 Pinokio 里打开应用，点 Install 再 Start。维护者称已在 Windows、macOS 和 Linux 测过安装器。
  2. 终端：需要 Node.js 24.x（24.14.0 或更新，建议 24.22.1+）或 26.x（建议 26.12.1+）；克隆仓库后 npm ci、npm run doctor、npm run dev，打开 http://localhost:4173。Node 25 已结束支持。
  3. Docker：docker compose up，同样使用 4173 端口。本地 MCP 与 ChatGPT OAuth 语音在 Docker 下不可用，语音需改用 OpenAI API 密钥。
  4. GitHub Codespaces：需 GitHub 账号；经转发 HTTPS 地址时 Overpass 与 OpenAI 语音令牌会返回 403，这些功能应在本地使用。

密钥在应用右下角的 POWER UP 面板里添加，不要先改仓库里的文件。默认只绑定本机；若把服务共享到局域网，等于把已配置的密钥代理给能访问该地址的人。官网同期写明：官方托管版仍是 Coming soon，可加入等候名单；其他自称托管或收费的 “God's Eye View” 站点与作者及 Halfpixel 无关。

这份东西为什么存在

God's Eye View 把公开信号收进同一颗可探索的地球。实时跟踪世界。和它说话。拆开它。扩展它。

飞行应答机、船舶信标、轨道根数、地震仪和公共摄像头，本来就已经在讲述这个世界。God's Eye View 把它们放在同一处，让你能从全球图景走到某一架飞机、某一艘船或某一条街道。它在你的浏览器里本地运行，源码可以检查和扩展。

作者的原话是：Half the magic is that it looks like a forbidden cockpit. The other half is that every line of code is inspectable.

多数数据源是实时的，或会定期刷新。交通是沿着真实道路、用汇总位置数据模拟出来的。闭路摄像头的姿态和火箭发射轨迹是粗估计。

先从附带的数据源开始，再加入你自己的。每一层都是单独的模块。

它能做什么

  • 驾驶舱视角：坐进被跟踪的航班里——相机会一路把下方地形保持在你脚下。
  • 近距目标名单：目标周围 250 公里内的名册——可逐步浏览实时飞机，并进入任一驾驶舱。
  • 点击即跟踪：相机锁定、画出渐隐尾迹、显示完整元数据；被跟踪的火点或船只可一键交给最近的实时摄像头。
  • 语音白板：对着世界说话做标注——真正的边界多边形、标记和路线。
  • 三维机库：按机型的真实三维模型——787、ATR-72、Citation、Bell 206、MQ-9——被跟踪目标在靠近时会从符号换成三维模型。
  • 重绘现实：在普通地球上叠加 GLSL 传感器外观——CRT、夜视、FLIR/热成像、Noir。
  • 探测叠加：视口里每一目标的屏幕空间包围盒与编号。
  • 军用抬头显示：带情报风格遥测的战术 HUD。
  • 全球上下文：一键铺开完整态势，离开时回到你原来的精确视角。
  • 场景导演：为短片和演示捕捉电影感相机巡游。
  • 分享链接：相机、风格、图层，甚至一个被跟踪目标，都可以序列化进 URL——实时目标是交接，不是书签。
  • 重置地球：一个控件——或一句话——回到完整地球。
  • 天气：播放 GFS 或 ECMWF 预报风场，回放实测雷达、卫星云图和闪电，并跟随 NHC/CPHC 气旋路径。无需密钥。
  • 已标注的车牌识别摄像头：OpenStreetMap 中标记的车牌识别摄像头位置，一次一座城市。只有位置和标签；无需密钥。
  • 卫星过境：用语音询问任一已加载卫星下次从你所在地上空升起的时间：升起、最高点和落下，以及是否可见。
  • 分析师问答：用语音统计、筛选和排序卫星、数据中心和水坝，也可问航班、船舶、火灾和地震；答案会说明源是否过时或已回退。
  • 倾斜与北朝上：在正射和下俯 35° 斜视之间切换，或把北方放到上方，被跟踪目标保持居中。
  • 无需密钥的搜索：输入十进制坐标、二维 WGS84 的 geo: URI（例如 geo:39.7392,-104.9903），或附带的城市、地标，即可飞过去，不必请求地理编码器；其他名称在已配置时走 Google，再回退到 Photon 和 Nominatim。
  • 可分享场景：把导演场景作为文件或包导入、预览和分享，含相机锚点、编写的运镜和数据包。
  • 尼泊尔洪水场景：回放 Bhote Koshi 洪水：洪水路径、目击者来源和前后影像（捆绑数据不可商用；见 DATA_SOURCES.md）。

快速开始

本地安装不需要账号或 API 密钥。应用打开时使用 Esri 卫星影像和无需密钥的地形。若 Esri 无法访问，则回退到 OSM。航班、军用交通、卫星、地震、公共摄像头、广播和发射任务均可在无密钥时使用。

若要摄影级三维，可为符合条件的个人非商业用途添加 Cesium ion 令牌，或使用 Google Maps 密钥走直接、计量的路线并使用 Google 地点搜索。须遵守提供方条款与配额。密钥通过应用内的 POWER UP 面板添加；密钥与费用一节说明选项。

若已安装过：请更新到最新版本。旧版本会查询公开的 OpenStreetMap Overpass 服务器，后者现已拒绝这些请求，因此交通、已标注设施和车牌识别图层会一直空着，直到你更新。

路径 1 —— 一键，不用终端

  1. 安装或将 Pinokio 更新到 8.2 或更新版本。
  2. 打开 Pinokio 中的 God's Eye View。
  3. 点击 Install，再点 Start。

可用于 Windows、macOS 和 Linux。Pinokio 维护者称已对修复后的安装器做跨平台测试。启动器会安装锁定的依赖、寻找空闲的本地端口，并在系统浏览器中打开应用。Server 菜单项可继续查看启动器控制台。

以前试过、安装失败？更新 Pinokio 后再试。8.2 修复了启动器安装问题；细节见 Pinokio 维护者的说明。

若使用较旧启动器，或手动打开内嵌视图？如果地球非常卡顿，先不要当成 GPU 兼容或最低硬件问题：把 Pinokio 显示的本地服务器 URL 复制到你平常使用的、启用了硬件加速的浏览器中打开。有一位 Pinokio 8.2.0 用户报告，内嵌视图严重卡顿，但同一正在运行的服务器在外部浏览器中恢复正常（#365）。这指向内嵌浏览器，而不是应用服务器或你的硬件；它并不能据此确定最低 GPU 要求。

路径 2 —— 终端 / 编码智能体

请使用 Node.js 24.x（24.14.0 或更新）或 26.x；24.22.1 或更新（26 线上为 26.12.1 或更新）包含 2026 年 10 月 21 日的安全修复，其中包括 CVE-2026-111497。安装医生会对已结束支持的 Node 25 发出警告。

git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run doctor
npm run dev

打开 http://localhost:4173。在首次运行面板中选择 Live Contacts、Space Missions、Environmental 或 Explore Manually。

启动性能：一次时点的 M5/Chrome 采集测得中位 1.86 秒冷启动。这是对照基线，不是对你的机器或网络的保证。见 docs/PERFORMANCE.md。

macOS 快捷方式：./scripts/dev-fresh.sh 会清理 Vite 缓存，并从钥匙串拉取已配置的密钥。它也可以在无密钥时启动。

路径 3 —— Docker

不必安装 Node；容器会发布同一套开发服务器。

git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
docker compose up

同样打开 http://localhost:4173。应用保存的一切都留在你克隆的目录里，所以 docker compose down 不会丢掉它们：

  • .env —— 你的 API 密钥，无论是从 Provider Settings 保存还是手写。
  • .gev-cache/ —— 下载的地图和卫星数据，使以后启动更快。
  • .gev-logs/ —— 日志。

备份这个文件夹就备份了全部内容；删除 .env 即可忘掉密钥。源码修改仍会热重载。端口只发布到 127.0.0.1，默认行为与本地安装一致。

本地 MCP 服务器和 ChatGPT OAuth 语音在 Docker 下不可用；语音请使用 OpenAI API 密钥。

若要对外发布，属于后文「共享实例」的显式选择，而且会一并交出 Provider Settings：启动器把容器网关当作本机，更宽的发布会让其他人也从同一地址进入。若打算共享实例，请改用手写把密钥放进 .env。SECURITY.md 有细节。

扩大发布范围时，同时设置 GEV_KEY_SETUP_TRUSTED_PEERS=none，使启动器不信任任何网关地址。

GEV_KEY_SETUP_TRUSTED_PEERS=none docker compose up

Compose 会从你的 shell 或项目 .env 转发 GEV_KEY_SETUP_TRUSTED_PEERS 和 GEV_ALLOWED_HOSTS；已导出的 shell 值优先。也可以把 GEV_KEY_SETUP_TRUSTED_PEERS=none 写进 .env 作为持久设置。未设置或空白的受信任对等仍会自动发现网关；none 会明确关闭它。启动日志会确认没有额外受信任的对等方。

在 Linux、NAS 或反向代理后运行

请用应当拥有其写入文件的那个用户来运行。id 可查看编号；在 Linux 上对自己可以这样：

env UID=$(id -u) GID=$(id -g) docker compose up

在 NAS 上，把仓库克隆到你希望存放数据的共享目录，并使用该共享所有者的 id：

cd /volume1/docker
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
env UID=1026 GID=100 docker compose up -d

请保留 env：bash 把 UID 视为只读，命令前单独写 UID=1026 会被静默忽略。若容器无法写入检出目录，启动时会说明。macOS 和 Windows 上的 Docker Desktop 会替你映射所有权。

在 SELinux 主机（Fedora、RHEL）上，compose 使用 :z 挂载检出目录以便容器读取；Docker 可能为容器访问重新标记该目录，大型检出可能需要一点时间。若没有这一步，启动会失败并提示 Cannot find module '/app/scripts/docker-start.mjs'。

若在反向代理之后，把密钥放进 .env 或作为环境变量传入——Provider Settings 会故意拒绝经代理的请求——并加上你对外提供的主机名，例如 GEV_ALLOWED_HOSTS=globe.example.lan（见「共享实例」）。地图路由会比较浏览器的 Origin 与服务器看到的 Host，因此代理必须传递原始 Host；若由代理终止 TLS，还要传 X-Forwarded-Proto。Caddy 默认两者都会做；nginx 需加上 proxy_set_header Host $http_host;、proxy_set_header X-Forwarded-Proto $scheme; 和 proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;。在 Docker 之外的安装上，该转发头也会把代理用户与你自己的浏览器分开限流。在默认 Docker 桥接网络下，主机上的每个客户端（包括你的浏览器）都从网关地址到达容器，并共享同一个 Overpass 配额桶。

仅 IPv6 的网络、重建镜像，以及测试套件

启动器读取 IPv4 默认网关，因此仅 IPv6 的 Docker 网络会找不到网关：它会记录 No default gateway; Provider Settings stays loopback-only，面板会拒绝所有保存。这时请把手写密钥放进 .env，或在阅读 SECURITY.md 后用 GEV_KEY_SETUP_TRUSTED_PEERS 自行指定网关。

node_modules 有意留在镜像内，并在匿名卷中跨重启保留：若 git pull 改变了依赖，用 docker compose down -v && docker compose up --build 重建。镜像还跳过 Puppeteer 的 Chromium 下载以保持体积，因此 npm run test:track 需在主机上运行——npm run build 和 npm test 可在容器内运行。

路径 4 —— GitHub Codespaces（云端，无需本地安装）

Codespaces 需要 GitHub 账号。即便 .env 里有 API 密钥并配置了 GEV_ALLOWED_HOSTS，经其转发的 HTTPS URL 访问 Overpass 查询和 OpenAI 语音令牌仍会返回 HTTP 403。这些功能请使用本地安装。

codespace 在云端工作区运行开发服务器，因此 Node 和依赖不会落到你的机器上。地球仍在你自己的浏览器里渲染，图形需求与其他路径相同。GitHub Free 每月包含 120 个核心小时、无需绑卡——在默认 2 核机器上大约 60 小时。组织版与企业版不含免费配额；以当前条款与配额为准。

  1. 先 fork 本仓库，再在 GitHub 上打开你的 fork。
  2. 点击绿色的 Code 按钮，打开 Codespaces 标签，然后 Create codespace on main。
  3. 在 codespace 终端中运行：
nvm install 24 && nvm use 24
npm ci
npm run doctor
GEV_ALLOWED_HOSTS="$CODESPACE_NAME-4173.$GITHUB_CODESPACES_PORT_FORWARDING_DOMAIN" npm run dev

打开 Ports 标签，找到 4173，点击地球图标在浏览器中打开。端口默认是私有的，因此 URL 会要求 GitHub 登录。请保持私有：公开端口会让任何人使用该应用以及你 .env 中的密钥。

这里的 GEV_ALLOWED_HOSTS 是必需的，不是可选。开发服务器只响应它信任的主机名，转发端口会以 $CODESPACE_NAME-4173.$GITHUB_CODESPACES_PORT_FORWARDING_DOMAIN 到达。不设置时页面会显示 Blocked request. This host is not allowed. 前导点通配符会被有意忽略，所以要传入这个准确名称。

⚠️ codespace 可从互联网访问。应将其视为「共享实例」中更宽发布的情形。Provider Settings 在转发 URL 上不可用。永远不要提交工作区里的 .env。威胁模型见 SECURITY.md。

和它说话

独立应用在设置里的 AI Provider 下提供 OpenAI 和 Gemini，语音与聊天共用同一个选择。初始默认是 OpenAI；选择会保存在本浏览器。要使用 Gemini，在 Provider Settings 或本地 .env 中添加 GEMINI_API_KEY，然后选择 Gemini。GEMINI_LIVE_MODEL 默认是 gemini-3.8-live。长期密钥留在本地服务器上，由它签发受约束的一次性会话凭证。

更换提供方会结束当前对话。若语音已开启，新提供方会以同样的开放麦克风或按键说话模式开始；已按住的空格键不会被带走。Gemini 使用相同的地图动作和字幕，但没有 OpenAI 费用表或 MINI 档。当 Gemini 报告会话过期时，重新开始语音以开启新对话。AI Provider 设置不会改变由 OpenAI 支持的 AI HUD 摘要。

麦克风旁边的 CHAT 会打开无声回复的文字聊天。它使用所选提供方和同样的地图动作，从不索要麦克风。OpenAI 聊天需要 API 密钥（OPENAI_CHAT_MODEL），因此在 GEV_PREFER_CODEX_OAUTH 把 OpenAI 固定到 ChatGPT OAuth 时会关闭；Gemini 聊天使用单独的文本模型（GEMINI_CHAT_MODEL）。聊天和语音面板共用左侧面板的玻璃表面，位于停靠栏上方或停靠在右侧。

语音可以使用 OpenAI API 密钥，或在同一台机器上使用可选的、已登录的 ChatGPT/Codex OAuth 会话。API 密钥路径仍是默认。在 Provider Settings 中选择 ChatGPT OAuth，会复用已有的本地登录，或启动 Codex 浏览器登录流程，并在完成后选择 OAuth。OpenAI 密钥仍驱动 AI HUD 摘要：对当前视图作出简短、约五词的情报风格读出，并随你移动重新生成。

OAuth 选项是实验性的。OpenAI 为 Responses API 记录了 ChatGPT 套餐用量；尚未确认存在受支持的、可复用 Codex 令牌的第三方 Realtime 合约。成功签发令牌并不等于确立计费或支持条款。

GEV 会读取 Codex 的文件凭据，但不会写入或刷新它们。它检查令牌形态与过期时间，并把过期登录报告为需要重新认证。登录按钮运行 codex login，只允许一次待处理尝试，并报告退出失败或两分钟超时。CODEX_HOME 必须与 Codex 使用的目录一致。若 CODEX_AUTH_JSON 指向别处，请先另行登录或修正该不一致，再使用按钮。Codex 凭据存储必须使用 auth.json；仅钥匙串和仅内存的存储无法被 GEV 读取。在 Windows 上，登录按钮可能无法启动经 npm 安装的 Codex；请自行运行 codex login，再选择 OAuth。见 Codex credential storage。

若要做实时语音检查，可对本地开发服务器运行 node scripts/qa-voice-auth.mjs http://127.0.0.1:4189 oauth microphone.wav。请使用一段前三秒为静音、随后是短出口头回复请求的 WAV。把 oauth 换成 api-key 可检查 API 密钥路径。该检查会验证音频输入、完整的口头回复、用量、资源清理和重连。截图和不含凭据的结果保存在 .gev-logs/voice-auth/。

点击 GEV MIC，授予麦克风，然后直接说。这不只是一个语音遥控器：

  • 它知道自己在看什么。智能体在回答前会拉取实时场景上下文——包括坐标、街道名、已开启图层和视图尺度。飞行中问 "what city is this?"，它知道。
  • 实体问答。点击任一飞机、船舶或数据中心并问 "what's this?" 它会用该对象的实时遥测回答。
  • 视觉锚定。在街道尺度，它会读取视口截图以识别可读的招牌和建筑名，并被指示不得幻觉标签。
  • 电影感取景。"Show me the planes overhead" 会把相机拉回、调整角度，像导演一样框住实时交通。
  • 诚实且安全。智能体只确认已经成功的动作。你的 OPENAI_API_KEY 从不进入浏览器；客户端只得到短时会话令牌。若在 Provider Settings 中选择 USE CHATGPT OAUTH，本地服务器仅用该登录签发同一种短时 Realtime 凭证，并对非回环客户端拒绝 OAuth 路径。

街景

任一提供方的街道级照片都在同一个面板里。此构建附带 Mapillary（免费客户端令牌）、Google Street View（使用你的 Google Maps 密钥）、以及无需密钥的 KartaView 和 Panoramax。

设置。在 mapillary.com/dashboard/developers 注册一个具有 Read 权限的应用，复制其 Client Token（MLY|…）。把它贴进 POWER UP → Mapillary，或在 .env 中设置 MAPILLARY_CLIENT_TOKEN 并重启。没有它时，街景会从 KartaView 开始，Mapillary 徽章会提示该添加哪把密钥。Google Street View 使用已在 Google Cloud 中为其启用 Maps JavaScript API 的 GOOGLE_MAPS_API_KEY；其徽章默认关闭，因为每一张全景都会计到该密钥上。KartaView 和 Panoramax 什么都不需要：它们的公开 API 无需密钥。

使用。在 DATA LAYERS → Cameras 下打开 Street Level，或使用 STREET LEVEL 面板标题中的药丸按钮。每个提供方有自己颜色的徽章，同一时间只亮一个：点亮一个会关掉其他。Mapillary 免费，在已设置令牌时默认点亮；否则点亮 KartaView。缩放到街道尺度（低于 60 公里）才会出现覆盖线；从轨道上看，面板会提示你放大。IMAGERY（ALL / 360° / FLAT）和 SINCE 过滤适用于 Mapillary、KartaView 和 Panoramax；Street View 全景都是 360°，因此在点亮 Street View 时这些过滤会被隐藏。点击覆盖线可看到图像锥，点击锥体打开照片。点亮 KARTAVIEW（紫色）并放大到大约 6 公里以下：它的线是 KartaView 拥有照片的街道，点击一条会打开离点击点最近的照片，平面或 360°（拖动环顾），锥体沿行驶路线排列；‹ › 或 ← → 可沿行驶路线步进（Shift+← →、↑ ↓ 和 + − 用于环顾 360° 照片；手机上捏合缩放）。KartaView 已归档的照片会被跳过；若全部已归档，面板会说明。对 KartaView 而言，SINCE 按上传日期计算，与 KartaView 自己的地图一致（它不能按别的过滤），面板会在 SINCE 值旁注明（ANY DATE (by upload date)）；KartaView 在自己的服务器上过滤线条，对尚未画过的过滤区域可能需要数秒。点亮 PANORAMAX（橙色）可使用开放的联邦公共库（在法国和比利时最强）：大约 60 公里以下，它的线是序列。点击一条线会打开该序列中离点击点最近的图片，且不移动相机，平面或 360°，锥体沿周围序列排列；‹ › 或 ← → 逐步查看，两种过滤都适用。其说明文字会写出图片作者（或持有它的实例）和许可（多为 CC BY-SA 4.0；IGN 实例上的图片为 Licence Ouverte 2.0）。在 Google 3D 地图上（Google 的条款使 Street View 在其他底图上不可用，因此不会出现），点亮 GOOGLE STREET VIEW 并从约 3 公里以下点击一条街道，或按 OPEN STREET VIEW 打开视图中心处的 Google 全景；沿箭头步进。照片上方有 EXPAND（全屏；Esc 离开）和 FIT / FILL（Mapillary，以及平面的 KartaView 和 Panoramax 照片）。说明文字链到提供方站点上的图像，地球会为每个已开启的提供方署名（“© Mapillary contributors, CC BY-SA 4.0”、“Street View imagery © Google”、“© KartaView contributors, CC BY-SA 4.0”、“© Panoramax contributors, licence per picture”）。KartaView 自己的照片页对未登录访客会失败，因此其链接打开的是全尺寸照片。

分享链接会携带提供方开关和过滤（0.m.0 关闭 Mapillary，0.m.0_0.r.google-1 打开 Street View，0.m.0_0.r.google-0*kartaview-1*panoramax-0 打开 KartaView，0.m.0_0.r.google-0*kartaview-0*panoramax-1 打开 Panoramax，按应用写出的格式（0.m.0_0.r.kartaview-1 和 0.m.0_0.r.panoramax-1 也可以；省略 m 的链接会保持默认的 Mapillary 点亮），0.p.p 仅全景，0.s.365 最近一年）。要添加提供方，请在 src/layers/streetLevel/registry.js 实现约定，并在 src/app/layers/streetLevel.js 注册。

引擎盖下

地球如何处理实时数据：

  • 对世界稳定的图标。无论是否被跟踪，无论正俯视还是看向地平线，飞机和船舶在每一相机角度都指向它们真实的世界航向——通过逐帧的屏幕空间航向投影。不会自旋，也不会锁死在视口上。
  • 从断续数据得到平滑运动。实时源大约每 15–30 秒到达一次；地球渲染会落后真实时间一个间隔，并在已知定位之间插值。空隙由航位推算填补。
  • 诚实的卫星。SGP4 传播，轨道环通过 GMST 重对齐锁在卫星上——不漂移，也不每秒闪烁。
  • 落在真实地面上。实体高度与 Google 3D tiles 对齐，因此飞机会停在机坪上，摄像头会站在街角，而不是飘在空中。
  • 缓存与请求预算。OpenSky 额度调节器、TomTom 每日瓦片预算，以及磁盘缓存的 TLE，用来减少重复请求。这些控制不能替代提供方的配额或计费控制。
  • 服务端凭据。凡是接触私钥的 API（OpenAI、AISStream、OpenSky OAuth、摄像头帧）都经加固的服务端代理中转，带有 SSRF 防护、响应上限和经过清理的错误。浏览器能看到的密钥只有 Google Maps 和 Cesium ion（请在提供方处同时限制二者）。
  • 一套小栈。界面用 Vue 3 和 Pinia，地球用 CesiumJS，构建用 Vite——再加上用于行星的 Google Photorealistic 3D Tiles，以及用于语音的 OpenAI Realtime API。读起来快，改起来也快。

实时视频摄像头（HLS）

带有 "feedType": "hls" 且已注册 HTTP(S) .m3u8 URL 的闭路电视源，会通过监视平面和面板共享的、延迟加载的 hls.js 解码器播放。DelDOT 使用其官方 HTTPS HLS 目录链接。可用 CCTV_DELDOT_ENABLED=0 关闭该包。

服务器允许两个并发会话。每个会话在内存中最多保留 12 个分段和 24 MiB；单次下载上限为 8 MiB，时限十秒。没有分段文件，也没有 ffmpeg 进程。重定向、跨源引用、加密播放列表和非 MPEG-TS 分段会被拒绝。每个解码器有自己的客户端租约（每会话最多八个），包括原生 HLS。关闭它只会释放该租约；被遗弃的租约在 15 秒无访问后过期。最后一次释放会停止上游工作。失败的实时视频会使用已有的静帧 / Street View / 合成回退，那不是实时视频。本集成不支持仅 RTMP 的源。

共享一个实例

默认情况下，别人到不了你的服务器——它绑定在 localhost。若要在局域网上共享，必须显式选择（npm run dev -- --host 0.0.0.0 --port 4173，或在 macOS/Linux 上使用 HOST=0.0.0.0 ./scripts/dev-fresh.sh）。IP 地址可以直接用；若使用局域网主机名，请用 GEV_ALLOWED_HOSTS=globe.lan 添加它，因为绑定到 0.0.0.0 并不会信任任意 Host 头。但要清楚：⚠️ 一台在局域网可见的服务器，会把你已配置的 API 密钥代理给任何能访问它的人。对产生费用的端点，默认按 IP 节流（GEV_RATELIMIT_OPENAI_PER_MIN、GEV_RATELIMIT_GOOGLE_PER_MIN——调节方法见 .env.example），但首先应配置提供方配额、用量限制和计费警报：应用层节流不是计费上限，单靠预算警报也不会停止花钱。完整威胁模型见 SECURITY.md。

服务器被共享时，Provider Settings 会被关闭，因此远程用户无法进入密钥录入面板。

本启动器仍然禁用 Pinokio 的局域网和 Cloudflare 共享。若需要远程访问，请使用经过单独审查的认证代理。限制和威胁模型见 SECURITY.md。

负责，并且开放

这条线。本项目刻画的是事件、资产、基础设施和系统——飞机、船舶、卫星、火灾、摄像头、城市。它不为检索具名个人、人脸识别或追踪个体做功能，越过这条线的拉取请求不会被合并。在这里，人不是一种查询类型。

状态：一个仍在演进、用于探索与学习的开源客户端——地基很快、很好改，但不是加固过的生产服务。以 MIT License 发布。捆绑和实时数据集各有自己的条款——见 DATA_SOURCES.md。安全模型：SECURITY.md。想贡献？见 CONTRIBUTING.md。
