宣纸色的底上，几道墨色山脊在雾里叠着，右上角盖着一轮朱砂红日。这是 HITOFUDE「一筆」附件视频的封面帧。作者 Shubhu（@positronx_）说，这是一部给一款并不存在的游戏做的五十秒动画预告，全部用代码画成：没有图像生成，也没有视频模型。女剑士的剑是一支画笔，对手是一条会把画出的世界擦掉的纸龙；最后那一剑，是汉字「一」，也是作品的名字。源码在 GitHub 仓库 shubhu121/hitdude。仓库根目录和 package.json 里都没有许可证，本页只做导读，收录作者原帖的全文中译；不转载视频，也不全文翻译 README。

这是一件什么作品

就仓库 README 的题记，HITOFUDE「一筆」（One Stroke）是「一部给一款并不存在的游戏做的五十秒动画预告，全部用代码画成」。女剑士名叫 Sumi，兵器是一支比她还高的毛笔；敌人叫 THE BLANK，是一条会把画面擦成空白的折纸龙。她用一笔画出另一条龙，两条龙收成太极，最后一剑是汉字「一」——既是那一笔，也是标题。这些设定写在 README 与 SPEC.md 里；本页未观看成片，不能把分镜效果写成已经看过的画面。

同一仓库里还有 play/：README 说这是从短片里剪出来的可玩版本，用的是同一套笔触引擎。另有 game/ 目录，README 把它写作更早的三维桌面原型（画作摊在桌上，配一条折纸龙）。也就是说，作者一面强调成片「零三维」、只用二维画布，一面保留了一个较早的三维原型目录。本页打开过 game/index.html 的存在性（HTTP 200），没有审读其中的实现。

作者在原帖里把作品归给 Mythos，并写道：一次会话、十四个子智能体；十五个镜头、一千二百帧由代码画出；声音全部合成、不用采样。仓库正文没有出现 Mythos，也没有出现「十四个子智能体」。一次会话与子智能体的数目，只是作者自报，⚠️ 未独立核实。Mythos 是否就是 Anthropic 只向验证项目提供的 Claude Mythos，原帖没有写全称，本页也不把这层对应写成已核事实。

仓库里能核对到什么

2026-11-10 在核对 robots.txt 之后，打开了仓库公开页，并从 raw.githubusercontent.com 读取了 README、SPEC.md、REVIEW.md、package.json 以及若干源文件的开头，未调用 api.github.com，也没有进入 GitHub 禁止抓取的 /tree/、/raw/ 路径。

默认分支是 main，当时可见提交 2 次，当前提交为 248d243。仓库页显示创建于 2026-11-10 11:34（新加坡时间，UTC+8），比原帖早约二十三分钟。根目录可见 src/、play/、game/、tools/、renders/、assets/audio/，以及 SPEC.md、REVIEW.md、STORYLINES.md。README 提到的笔触引擎 src/core.js、世界与角色 src/world.js / src/actors.js、镜头文件 src/shots.js 与 src/shots2.js、声音脚本 tools/make-audio.mjs，以及 play/index.html，均能以 HTTP 200 取到。

src/core.js 开头把画布写成 1920×1080、24 帧，并注明这是笔触引擎，函数对其参数是纯的，不用 Math.random，也不读时钟。这与 README、SPEC.md「单张二维画布，只按影片时间绘制」的说法一致，但不能代替对成片逐帧核对。SPEC.md 与 REVIEW.md 都把成片写成 50 秒、24 帧、十五镜、一千二百帧；附件视频的时长也是 50 秒。这些数字互相吻合，⚠️ 本页没有打开 renders/hitofude.mp4 去数帧。

渲染工具在 README 与 package.json 里都指向 HyperFrames（HeyGen），脚本钉在 hyperframes@0.9.27。仓库里的 AGENTS.md 与 CLAUDE.md 内容相同，是 HyperFrames 项目的通用说明，不是一份针对本片的制作手记。本页没有打开 HyperFrames 的产品站点。

声音方面，tools/make-audio.mjs 开头写它不依赖外部库，用确定性的伪随机数合成，并写出 50 秒、48 kHz 的 assets/audio/score.wav。该 wav 在核对日返回 HTTP 200，本页没有下载，也没有试听。REVIEW.md 里有一组响度读数，并写明「测过，但还没有人听过」。⚠️ 「零采样」是仓库与原帖的共同说法，本页未对音频做来源分析。
