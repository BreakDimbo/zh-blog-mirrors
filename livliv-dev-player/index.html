LivLiv Player：轻量 Web 2.5D 角色播放器（口型同步 + 摄像头面捕）

Lightweight 2.5D web character player · 项目导读 + 官方中文 README

来源 · GitHub · livliv-dev/player（Apache-2.0）收录 · 2026-11-06查看原文 ↗

项目：github.com/livliv-dev/player · LivLiv · 代码 Apache-2.0（2026-11-06 核 LICENSE）· 演示 livliv-dev.github.io/player

LivLiv Player（npm 名 @livliv/player，仓库版本 README/package 记为 0.2.0）是一套面向网页的轻量 2.5D 角色播放器：几行代码就能把角色放进页面、直播叠加层或应用。核心是无依赖的 WebGL2，gzip 后约 30 KB；同一套 API 可播放 LivLiv 模型包、VRM 与 PNGTuber，并按需加载浏览器内口型同步与 MediaPipe 摄像头面捕。

版权说明：代码与文档适用 Apache License 2.0（另有 NOTICE；2026-11-06 核 raw LICENSE）。仓库自带的 21 个精选角色不适用 Apache，见 characters/LICENSE.md（个人非商业、需署名、禁商用/单独分发/训练 AI 等）；Kujira / Kujira Q / Pen 另见 CREDITS。README 写明两份许可都不包括 LivLiv 名称与标志。因此本页不转载角色贴图、demo 动图或 wordmark；演示请到原仓库与 GitHub Pages 示例站 / livliv.ai/discover。附录采用仓库官方 README.zh-CN.md（非本站另译）。

它是什么

  • 定位：网页端 2.5D 角色「播放器」，不是 Live2D Cubism SDK；不读 .moc3 / .cmo3。README 声明与 Live2D Inc. 无关联。
  • 核心规格（README）：WebGL2、核心无第三方依赖、约 30 KB gzip；需 ES2023（Chrome/Edge 97+、Firefox 104+、Safari 15.4+）。
  • 格式：LivLiv 包（.livliv / model.json v4，见 FORMAT.md）、VRM（需 three + @pixiv/three-vrm）、PNGTuber（开/闭口图，可选闭眼）。
  • 能力：表情与动作（如 smile / nod）、口型参数、麦克风/音视频口型同步（createSpeech）、摄像头面捕（MediaPipe，按需导入；画面留在本机）。
  • 分发：README 写「尚未上 npm」，需从本仓库 npm run build 后引用 dist/index.js。package.json 记 private: true、version: 0.2.0。
  • 演示：示例站；本地 /example/demo.html 等。也可用 iframe 嵌 https://livliv.ai/live/<id> 作 OBS 浏览器源。

怎么用

README 给出的最小示例：

import { Player } from '@livliv/player'

const player = new Player(document.querySelector('canvas'))
await player.load('characters/k01/')

player.setExpression('smile')
player.act('nod')
player.params.mouthOpen = 0.6

口型与面捕、VRM/PNGTuber 用法见附录官方中文 README。完整选项见仓库 API.md（英文）。

特点：

  • WebGL2，无依赖，核心 gzip 后约 30 KB
  • 口型同步（麦克风、音频、视频）和摄像头面捕（MediaPipe），都在浏览器里运行，按需引入
  • 支持 LivLiv、VRM 和 PNGTuber 三种角色，用同一套接口
  • characters/ 里有 21 个精选角色，可以直接用

试一试

  • 在线：示例页在 livliv-dev.github.io/player。
  • 在本地：npm install && npm run build，用任意静态服务器打开这个目录，访问 /example/demo.html

（表情、动作、麦克风、摄像头；?model=../characters/<id>/ 换一个角色）。/example/png.html 和 /example/vrm.html 是 PNGTuber 和 VRM。

  • 在 livliv.ai 上：那里的每个角色页都用同一套渲染播放这个角色。从 livliv.ai/discover 开始。

在自己的页面里用

import { Player } from '@livliv/player'

const player = new Player(document.querySelector('canvas'))
await player.load('characters/k01/')   // 含 model.json 和 textures/ 的文件夹，或一个 .livliv 文件

player.setExpression('smile')          // 可用的 id 在 player.expressions 里
player.act('nod')
player.params.mouthOpen = 0.6          // 0..1

口型同步和面捕：

import { createSpeech } from '@livliv/player/voice'
import { startFaceTracking } from '@livliv/player/tracking'   // 需要 @mediapipe/tasks-vision

const speech = createSpeech(player)
button.onclick = () => { speech.unlock(); speech.say('/reply.mp3') }

await startFaceTracking(player)

VRM 和 PNGTuber 用同一套接口：

import { BodyPlayer } from '@livliv/player/body'
import { VrmBody } from '@livliv/player/vrm'    // 需要 three 和 @pixiv/three-vrm
import { PngBody } from '@livliv/player/png'

const vrm = new BodyPlayer(canvasA, new VrmBody())
await vrm.load('/avatars/me.vrm')
const png = new BodyPlayer(canvasB, new PngBody())
await png.load({ closed: 'me-closed.png', open: 'me-open.png' })

完整的 API 见 API.md（英文）：选项、参数、表情和动作、驱动、VRM 和 PNGTuber、不可信文件的上限、模型包和格式版本。LivLiv 模型包格式（.livliv、model.json v4）见 FORMAT.md，JSON Schema 在 schema/；v4 之前导出的模型包见 FORMAT-v3.md，照样能播放。

还没有发布到 npm：请从这个仓库构建，引入 dist/index.js。

精选角色

characters/ 里有 21 个角色，可以直接 load()。它们右下角带一个小小的 LivLiv 标，播放器会画出来。它们不适用 Apache 许可。大部分由 LivLiv 制作：个人非商业用途可以免费使用，请署名（「角色：LivLiv（livliv.ai）」）；不能出售、不能商用、不能用来训练 AI 模型。Nana 是 LivLiv 的吉祥物。完整条款见 characters/LICENSE.md。

Kujira、Kujira Q 和 Pen 来自别人的作品，不适用上面的许可和署名。它们的来源、署名和条款见 characters/CREDITS.md。

角色列表见英文 README。

用自己的角色

可以导入 PNGTuber 的几张图，或 VRM（用 three.js 画）；也可以在 livliv.ai 用一张图做出自己的角色。

  • PNGTuber：两张图（闭嘴、张嘴），有闭眼的两张更好。
  • VRM：VRoid Studio 或任何能导出 VRM 0.x / 1.0 的工具做的。
  • LivLiv 模型：在 livliv.ai 用一张图做出角色，在角色页下载模型包（一个 .livliv 文件），直接传给 load()（URL，或用户选的 File），解压后的文件夹也可以。免费版的模型包带 LivLiv 水印，播放器会画出来。

关于播放器和角色

LivLiv Player 和 .livliv 格式是 LivLiv 独立做的，没有用 Live2D 的软件或 Cubism SDK，也不读 .moc3 / .cmo3 文件。「Live2D」是 Live2D Inc. 的商标，LivLiv 与其无关联。

在 livliv.ai 上制作角色会用到 AI。播放器本身只负责播放：不调用 AI 服务，只读取你指给它的文件。面捕在浏览器里运行 Google 的 MediaPipe，摄像头画面不离开设备；网络方面的细节见 API.md。

仓库里的精选角色也是在 LivLiv 上做的，同样用到了 AI；Kujira、Kujira Q 和 Pen 改编自别人的角色（来源）。Nana 精修版（d03ft）另外用 LivLiv 自己的工具加了会摆动的部件和转头的关键形。

模型包里的 meta.author 和 meta.license 记的是署名和使用条款，请保留并遵守。公开展示用 LivLiv 做的角色时，请注明 AI 参与制作，不要说成手绘或人工绑定的作品。

不写代码，直接嵌入

<iframe src="https://livliv.ai/live/k01" width="480" height="640" allow="camera; microphone"
  style="border:0;background:transparent"></iframe>

同一个 /live/<id> 页面背景透明，可以直接作为 OBS 的浏览器源。

开发

git clone https://github.com/livliv-dev/player
cd player
npm install
npm run check          # 类型检查
npm run build          # dist/：index.js、tracking.js、voice.js、body.js、png.js、vrm.js（ES 模块）、chunks/ 和 types/
npm test               # 单元测试和模糊测试（Node 22.18 及以上，不需要浏览器）
npm run test:browser   # 在无头 Chromium 里画出每个精选角色；先执行一次 npx playwright-core install chromium-headless-shell

src/runtime/ 是 livliv.ai 自己在用的渲染和动作代码，这个仓库从它发布。参见 CONTRIBUTING.md。安全问题请按 SECURITY.md 报告。

浏览器支持

需要 WebGL2 和 ES2023：Chrome / Edge 97+、Firefox 104+、Safari 15.4+，桌面和手机都可以。
