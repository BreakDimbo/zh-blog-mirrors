AI digital-human talking-head videos from one photo

一句话：这是一个装进 AI 编程 Agent（Claude Code、Codex 等）的“数字人口播”技能包。你给它一张照片和一句需求，它会写稿、报价、通过 Renoise MCP 调用 Grok Video 1.5 分段生成会对口型的数字人片段，再在本机用 ffmpeg、whisper 和 Remotion 做质检、修音、字幕和头部博主风格的包装，最后输出 MP4 成片。

它是什么

Digital Human Koubo（“口播”即对着镜头讲话的短视频）不是一个独立 App，而是一套写给 AI Agent 执行的流程：一个标准 SKILL.md（开放的 Agent Skills 格式）加上 Python / Shell 脚本和三套 Remotion 剪辑模板。Agent 读 SKILL.md，按步骤调用远程 MCP（生成视频）和本机命令（下载、质检、剪辑）。

仓库里实际有两个 Skill：

  • digital-human-koubo（主 Skill）：固定数字人形象、写稿切段、报价、生成、质检、修音、对齐、剪辑包装。
  • finance-explainer：风格 A“小林式财经 / 科技解说”的引擎——选题打分、带出处的事实清单、拍表 episode.json、主播全屏 ↔ 小窗的“放大缩小”、图表与文档标黄，示例有硅谷银行（SVB）和 AI 芯片两期。

输入：一张人物照片（或仓库自带的形象）+ 一段内容或一句需求。输出：横屏 16:9 或竖屏 9:16 的 MP4 成片（响度 -14 / -16 LUFS），以及中间产物 brief.json、script.json、逐字时间轴 tl.json、剪辑描述 edit.json 等。

它能做什么

  1. 固定形象。脸、服装、声音描述、提示词模板都写在 persona.json，每条片子都是同一个人；还可以有第二主播（用户本人）和“橘猫店长”“柴犬主播”等角色。要进直播间、门店、街景，先用 GPT Image 2.5 合成开场画面，再当参考图让人物开口。
  2. 先报价，再花钱。生成前 Agent 先报“段数 · 秒数 · 预估积分 · 余额”，用户确认才生成；先拍第 1 段确认音色，再批量。
  3. 两道质检。每段用 whisper 回听并与稿子比对；每段抽 4 帧看画面——Grok 偶尔会自己往画面里烧字幕，有就重拍。
  4. 声音统一。1/3 倍频程频谱匹配 + 去齿音 + 同一小房间混响 + 响度统一，让几十段分开生成的口播听起来像一次录完（作者实测齿音段间差 13.2 dB → 5.9 dB）。
  5. 5 种剪辑风格 + 48 个包装组件。作者逐帧拆了 25 支头部博主视频（MrBeast、MKBHD、影视飓风、何同学、Vox、Kurzgesagt、半佛仙人等），把开场钩子、数字钉子、证据截图、地图航线、弹幕、投票、章节卡等做成可按名字调用的 Remotion 组件。
  6. 景深字。大字放在背景和人之间：macOS Vision 人像分割 → 透明视频 → 三层合成。
  7. 多语言。英、日、韩、法、西、阿拉伯语实测，whisper 回听准确率 94–100%。

架构与工作流

你的内容 ─► 0 环境检查：Renoise MCP（get_account）/ ffmpeg / whisper（doctor.sh，已装则跳过）
           1 诊断内容 → 推荐 2 种风格 → 一次问完 → brief.json
           2 写稿 script.json（每段 ≤15 秒，中文约 5.4 字/秒，标 shot: full/pip/vlog/depth）
           3 build_tasks.py 切段 + 报价 → 用户确认 → 先拍第 1 段 → 批量 create_tasks / wait_tasks
           4 rangedl.py 分片下载（6 段 Range 并发 + 断点续传 + ffmpeg 解码校验）
           5 assemble.py：whisper 回听比对、裁到说完后 0.25 秒、拼接、loudnorm；每段抽 4 帧
           6 voicefx/unify.py 声音统一；align.py 出逐字时间轴 tl.json
           7 Remotion 剪辑：new_edit.sh 起工程 → edit.json / pack 组件 → check_edit.py 预检
           8 渲染 → 看过渡中间帧 → 响度 -14 / -16 LUFS → MP4

分工很清楚：云端只负责“生成会说话的画面”（Renoise MCP 上的 Grok Video 1.5，也写了 Wan 3.0、OmniHuman 的用法）；本机负责一切可检查、可重做的后期；Agent负责按 SKILL.md 串起流程并在花钱前停下来问人。剪辑层是数据驱动的：组件写进 pack 数组，时间用“段:词”锚定（如 "3:积分"），由逐字时间轴换算成帧，9:16 自动适配。

怎么用

  1. 准备 Agent。需要三样能力：能装 Agent Skills、能接远程 MCP、能在本机执行命令。Claude Code 是作者实测环境；Codex 预期可用；OpenClaw、WorkBuddy 等“应可用”。只能聊天 + MCP 的 Agent 可以写稿、报价、生成，剪辑交给能跑命令的 Agent。
  2. 安装 Skill。git clone 后把 skills/digital-human-koubo 与 skills/finance-explainer 复制到 ~/.claude/skills/（Codex 为 ~/.codex/skills/）。
  3. 接入 Renoise MCP。注册 Renoise 账号，添加远程 MCP https://renoise.ai/api/public/mcp（浏览器登录授权，无需复制 API key），问 Agent“查一下我的 Renoise 余额”验证。
  4. 本机工具。ffmpeg、Python 3（numpy、Pillow）、Node.js 18+、whisper.cpp 与 ggml-medium-q5_0 模型；bash scripts/doctor.sh 一键检查。景深字需要 macOS。
  5. 用大白话下单。例如“用这个数字人做一条 30 秒直播间广告：WorkBuddy 上手课，10 节课 99 元，原价 999。”之后按报价确认 → 看第 1 段 → 批量 → 出片。
  6. 做自己的数字人（可选）。用本人或明确授权的正脸照片生成四视图，对比 Grok / Wan 选模型，上传参考图后把 material:<id> 写进 persona.json；仓库里的 material ID 属于作者账号，别人用不了。

作者给出的真实成本：27 秒直播间广告 482 积分；4 分 36 秒教程约 3,250 积分；5 分 55 秒升级版约 3,409 积分（Grok Video 1.5 720p 17 积分/秒、480p 10 积分/秒，以实时报价为准）。

局限与注意事项

  • 依赖付费云服务。核心的视频生成走 Renoise（按积分计费）；没有本地生成路线。README 中的 Renoise 链接都带推广追踪参数（utm），SKILL.md 还要求 Agent 原样给出带 utm 的注册链接——读者可自行判断其商业关联。
  • 口型绑定生成的声音。Grok 的口型跟它自己生成的声音走；事后换成 MiMo 克隆声或别的声音，口型会差约 100 毫秒，全屏特写看得出。要用自己录音又要口型准，需换 OmniHuman 等音频驱动模型。
  • 生成模型的不稳定性。Grok 横屏偶尔自己烧字幕、偶尔漏念语气词；whisper 会把中文数字写成阿拉伯数字导致“误判”；美国 CDN 并行下载会断——这些都要靠质检脚本兜底和重拍，重拍也要花积分。
  • 平台限制。景深字依赖 Apple Vision，仅 macOS；Claude 桌面端 / 网页只有沙盒，无法完成本机剪辑。除 Claude Code 外，其他 Agent 多为“预期 / 应可用”，未逐一实测。
  • 许可分层。MIT 只覆盖代码和文档；示例视频、主播形象图、风格预览和图鉴里的人物是作者的 AI 数字人，NOTICE 明确不得当成自己的作品上传、不得使用其形象。Remotion 对 3 人以上公司需购买授权；Noto 动态表情为 CC BY 4.0，需署名。
  • 伦理红线。作者要求只用本人或明确授权的脸和声音、每条片子标注“内容由 AI 数字人演绎”、不编造价格与评价。“小林式”风格只学结构与剪辑语法，不得使用真实创作者的脸、声音和原话。数字人带货广告在各平台的标注规定需自行核对。

finance-explainer：把“小Lin说式”解说写成流水线

上次只简单提了这个副 Skill。读完 SKILL.md 和 6 份参考文档后，可以确定它是整个仓库里流程最严的一部分：

  • 先查事实再写稿。research.py 找线索、打开原文核对，写成 facts.md：每条都是“事实 — 日期 — 来源 URL”；剧本里的数字必须能在清单里找到，查不到的标 ⚠ 且不进剧本，主播可以直接说“这个我没查到”。
  • 剧本就是拍表。episode.json 每一拍写一段口播、一个主画面（主播全屏 / 侧边 / 小窗 / 下场，或图表、空镜）和若干叠加卡片，用 [[cue]] 标卡点。三种骨架：危机型、收购博弈型、悖论型。文案指标写得很具体：成片约 6 字/秒，每分钟 1–2 个设问、3–4 个带参照物的数字。
  • 首选真人录音。align_recording.py 按停顿把长录音切开逐段转写，口误只留最后一遍，拍内长停顿压到 0.16 秒；MiMo 预设音色只是占位。这一点和主 Skill（默认用 Grok 原生配音）不同。
  • 频道拆解有数据。channel-teardown.md 写的是 160 支视频的元数据、97 支字幕统计、6 支逐帧分类（⚠️ 作者自报，原始数据未随仓库提供）。
  • 小问题：SKILL.md 里提到的 promo-video、ai-teardown 两个 Skill 不在本仓库，大概是作者自己的其他工具 ⚠️ 推断。

合规与伦理：数字人的脸和声音

以下是本站补充的背景，不是法律意见；各平台、各地区的规则要以最新原文为准。

  • 仓库自己的红线写得比较全：只用本人或明确同意的脸和声音；不冒充真人；“小林式”只学结构，不用真实创作者的脸、声音、布景和原话；生成前先报价。finance-explainer 还要求做“身份核查”：用户给的脸如果被说成某位真实创作者，或者只是把真人照片改了发型眼镜，就不用。
  • 中国大陆的 AI 标识规则：《人工智能生成合成内容标识办法》自 2025-09-01 起施行，第十条要求用户发布 AI 生成合成内容时主动声明并标识；配套强制性国家标准 GB 45438—2025 规定，视频的显式标识文字要同时含“人工智能 / AI”和“生成 / 合成”，放在起始画面的边角，字高不低于画面短边的 5%，至少显示 2 秒（网信办原文）。
  • ⚠️ 推断：主 Skill 的默认标注可能不够。persona.json 里写的标注是“内容由 AI 数字人演绎”，其中没有“生成 / 合成”字样；finance-explainer 用的角标“AI 生成数字人演示 · 非商用”则符合上述要素。在大陆平台发布时，建议把字样、位置、字号、时长都按 GB 45438 核一遍。
  • 肖像与声音：《民法典》第 1019 条禁止“利用信息技术手段伪造”他人肖像，第 1023 条规定声音参照肖像权保护；《互联网信息服务深度合成管理规定》第十四条要求提供人脸、人声编辑功能的服务提示使用者告知被编辑的个人并取得单独同意。也就是说，拿别人的照片或声音做数字人，风险不只在平台规则。
  • 仓库里的人物不能拿来用。NOTICE 写明：MIT 只覆盖代码和文档；白背心主播、作者本人的形象都只供演示。persona.json 里的 material: ID 属于作者的 Renoise 账号，别人本来也调不了。
  • 利益关联：README、THIRD_PARTY 与 SKILL.md 中的 Renoise 链接都带 utm_source=official，最后两次提交专门加上这个参数；SKILL.md 还要求 Agent 原样给出这条链接。演示片“产品推荐口播”的文件名是 renoise-koubo-huazi。作者和 Renoise 有没有合作或分成，仓库里没有说明 ⚠️ 推断，读者可自行判断。

小结

这个仓库的价值不在某个新模型，而在把一整条短视频生产线写成了 Agent 能照做的 SOP：花钱前停下来问人、每一段都有机器质检、声音和画面的“缝”都有脚本去缝、包装手法被拆成可调用的组件。与 AvatarScript 那种从头像 rig 出发、强调可复现的路线相比，它更贴近当下内容创作者的实际需求——真人感、快、可商用——代价是依赖付费云模型和更多的重拍成本。

能做什么

  • 一张照片做出固定的数字人：脸、服装、声音描述、提示词模板都存在 persona.json，每条片子都是同一个人。想进什么场景（直播间、门店、教室、京都街头），先用 GPT Image 合成开场画面，再让她开口。
  • 对口型的口播片段：稿子切成 ≤ 15 秒一段，通过 Renoise MCP 用 Grok Video 1.5 生成。也写了 Wan 3.0、OmniHuman（用你自己的录音驱动口型）的用法。
  • 先报价，再花钱：每次生成前，Agent 先报「段数 · 秒数 · 积分 · 余额」，你点头才开始；先拍第 1 段给你看，满意再批量。
  • 两道质检：每段用 whisper 回听、和稿子比对；每段抽 4 帧检查（Grok 偶尔会自己往画面里烧字幕，有就重拍那段）。
  • 声音统一：1/3 倍频程频谱匹配 + 去齿音 + 同一个小房间混响 + 响度统一，30 段分开生成的口播听起来像一次录完（实测齿音段间差 13.2 dB → 5.9 dB）。
  • 按内容推荐剪辑风格：Agent 先诊断内容，推荐 2 种风格并附预览图，一次问完（风格 · 比例时长 · 花字强度 · 主播）。
  • 48 个包装组件：逐帧拆了 25 支头部博主视频（MrBeast、Mark Rober、Ryan Trahan、MKBHD、影视飓风、何同学、Johnny Harris、Vox、Kurzgesagt、回形针、半佛仙人、差评、毕导）。每种风格自带默认包装，想加减直接说。
  • 景深字：大字 / 数字放在背景和人之间（macOS Vision 人像分割 → 透明视频 → 三层合成）。
  • 多语言：英、日、韩、法、西、阿拉伯语实测，whisper 回听准确率 94–100%。
  • 多种 Agent 都能用：标准 SKILL.md Agent Skill + 脚本，只要能装 Skill、能接远程 MCP、能在本机跑命令，就能驱动整条流程。

踩过的坑（Skill 里都处理了）

  • Grok 横屏口播偶尔自己烧字幕，提示词写了也挡不住 → 抽帧检查，重拍那段。
  • whisper 会把中文数字写成阿拉伯数字（九百九十九 → 999），准确率会掉，但其实没念错 → 先听再决定重拍。
  • Renoise 美国 CDN 并行下载会断成半截 → rangedl.py 6 段 Range 续传 + 解码校验。
  • Grok 9:16 720p 是 720×1280，别拉成别的比例。
  • expo 缓动到不了终点（99.9 四舍五入成 100）→ 计数动画结束时强制落在精确值。
  • 主播视频轨一定要静音；两条声音差几毫秒叠在一起会刺耳（梳状滤波）。

使用红线

  • 只用你本人或明确授权的脸和声音，不冒充任何真人或创作者。
  • 每条片子标「内容由 AI 数字人演绎」，场景和动物片段标「AI 生成」。
  • 不编数字、价格、优惠、评价；画面上的示意数据要标「示意」。
  • 不用网络梗图、影视剧截图、明星照片；梗图类组件用你自己数字人生成的原创贴纸。
  • 积分只在你确认报价之后才花。
