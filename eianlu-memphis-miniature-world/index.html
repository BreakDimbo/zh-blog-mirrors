这是什么

  • 一份可以直接复用的“代码动画”提示词。Eian 前一天发了一支稻田俯视小动画，收藏 367 次，评论区很多人要方法。第二天他用同一种风格做了荷塘短片，并把完整提示词贴出来，最后一行留空：“场景：【在这里写你的场景】”。
  • 画面不是视频模型生成的。提示词让模型用 Canvas 写一个确定性的 frame(i) 函数，用无头 Chrome 逐帧导出，再用 ffmpeg 合成；配乐也用代码合成（五声音阶旋律加环境声）。有人问是不是 Opus 5.5 做的，作者回答“是的”；问用 skills 还是 prompt，作者回答“直接提示词”。
  • 和《一座城的年轮》是同一条路线。都是“让 Claude 写代码渲染每一帧”。不同的是，这次不靠真实数据，而是用风格约束把一个场景做成会动的微缩模型。

这种风格真的太适合做一些治愈系动画了！
又尝试了一些新的内容，比如这支荷塘风格的短片。

提示词：用代码做一支 20 秒的"孟菲斯微缩世界"小动画，1080×1080，60fps。
画面：把一个场景做成会动的微缩模型。暖白底，内容放在居中的圆角画框里，四周多留白；画框边缘是颗粒状消散的边（像喷漆），开场从中心颗粒状长出来，结尾收回去。
配色：孟菲斯风格。饱和原色 + 粉彩（黄 #FFC93C、粉 #FF8DB5、钴蓝 #2E5BE6、珊瑚红 #FF5A5F、薄荷绿 #A9E6C6、天蓝 #8DD3F6、淡紫 #D3BEFF），所有物体有深靛色 #25214A 描边和不模糊的硬投影，大色块上铺圆点、条纹、折线这类小图案。
镜头：一镜到底，缓慢匀速移动，可以带一点旋转和推近。
节奏：靠画面里的小动静撑起来，比如鸟飞过、云影掠过、鱼游、人走、车开、叶子飘落，至少安排一两个有"剧情"的瞬间。
文字：画框下方三行居中小字：标题（中英）/ 季节 · 一句描述（中英）/ 随镜头变化的经纬度。
做法：用 Canvas 写一个确定性的 frame(i) 函数，输入帧号输出一张图，场景按坐标和固定随机种子生成；用无头 Chrome 逐帧导出，ffmpeg 合成。配乐也用代码合成：五声音阶的轻旋律 + 环境声，画面里的事件要和音效卡上。
先给我看 4 张样帧拼图，我确认后再渲全片。
场景：【在这里写你的场景】

提示词拆解

这份提示词短，但每一行都在替模型做一个决定。逐段看：

段落规定了什么为什么有用
规格20 秒、1080×1080、60fps，共 1,200 帧方形画幅适合社交平台；先把帧数定死，后面的“慢”和“匀速”才有尺度。
画面暖白底、居中圆角画框、四周留白；画框边缘像喷漆一样颗粒消散，开场从中心长出、结尾收回画框把场景变成“桌上的模型”；颗粒进出场同时解决了开头和结尾，片子天然闭合。
配色7 个具体色值 + 深靛色描边 + 硬投影 + 圆点/条纹/折线小图案用色值代替“好看的配色”这类形容词；描边和硬投影让所有物体像同一套贴纸，风格一致性主要靠这一行。
镜头一镜到底，缓慢匀速，可带旋转和推近不剪辑就不用设计转场；慢推加微旋转是“微缩模型”观感的来源。
节奏鸟、云影、鱼、行人、车、落叶；至少一两个有“剧情”的瞬间画面信息靠小动静撑起来；“剧情瞬间”（比如青蛙跳水）给观众一个记忆点。
文字画框下三行：中英标题 / 季节 · 一句描述 / 随镜头变化的经纬度经纬度随镜头变化，是很省力的“真实地点”暗示，也让每支片都像同一系列。
做法Canvas 写确定性 frame(i)，坐标 + 固定随机种子；无头 Chrome 逐帧导出、ffmpeg 合成；五声音阶 + 环境声，事件与音效对齐同一帧号永远得到同一张图，可以只改某一帧、可以重渲；声音和画面共用帧号时间线，才能“卡上”。
评审关卡先出 4 张样帧拼图，确认后再渲全片全片渲染慢，先看静帧能便宜地纠正风格。评论区 @growaiskills 补充：样帧里留一张开场、一张收尾，顺便检查颗粒进出场和字幕边距，作者回“是的！”。
场景槽“场景：【在这里写你的场景】”前面所有行是固定的风格骨架，只换最后一行就能出新片，例如荷塘、成都平原、玉林路。

用之前值得知道的几点

  1. 镜头角度可以换。有人试了侧视，觉得还是俯视好看。作者说镜头都可以调，不一定要俯视；荷塘这支就是水面上下的剖面视角，玉林路是等轴测视角。
  2. 代码配乐能用，但作者自己更偏向找现成音乐。他的原话是“其实是可以的 不过没有自己找音乐好”。如果要用现成音乐，记得核对授权。
  3. 时间最好按秒算。评论区 @zealdin 建议在帧函数里用 i/fps 算时间，ffmpeg 合成时再指定 -framerate，这样以后改时长或帧率不用重写动画。这和本站多篇代码成片文章里的“渲染契约”是同一个意思。
  4. 模型与耗时。作者确认用的是 Opus 5.5、直接提示词，没有 skill；渲染时长和费用没有说明。
  5. “孟菲斯”在这里是配色语言。提示词里的孟菲斯主要指饱和原色加粉彩、粗描边、几何小图案，用来画写实场景的微缩模型，和 1980 年代孟菲斯设计里夸张的几何家具造型不完全是一回事。
