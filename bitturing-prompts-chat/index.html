一句话：prompts.chat 就是 2022 年 12 月那个最早的 ChatGPT 提示词清单「Awesome ChatGPT Prompts」改名后的样子。现在它是一个可以搜、可以收藏、可以自建的提示词平台，还收技能（skills）、工作流和 bot。提示词数据以 CC0 放进公有领域，网站代码是 MIT。除了网页，也能通过 CSV、Hugging Face 数据集、命令行、MCP 服务器和 Claude Code 插件来用。

项目是什么

仓库 f/prompts.chat 的简介是“f.k.a. Awesome ChatGPT Prompts”，也就是“原名 Awesome ChatGPT Prompts”。它最早只是一份 Markdown 清单，开头一句话让 ChatGPT “扮演 Linux 终端”“扮演英语翻译”之类，后来做成了网站。README 自称是“第一个提示词库（2022 年 12 月）”。

现在的 prompts.chat 大致有这几块：

  • 提示词库：网页上可按分类、标签、类型（文本 / 结构化 / 图像）筛选，支持 AI 搜索。网站列表页当时显示“2725 found”。仓库里的 prompts.csv（约 9.1 MB）有 2,772 行，字段为 act, prompt, for_devs, type, contributor，其中 TEXT 2,395 条、STRUCTURED 356 条、IMAGE 21 条（本站 2026-10-30 解析）。
  • 投稿与同步：在网站上提交提示词，会自动同步回 GitHub 仓库。
  • The Interactive Book of Prompting：一本 29 章以上的提示词工程互动教程，源码在仓库 src/content/book，MIT 许可。
  • Prompting for Kids：给 8–14 岁孩子的游戏化 AI 沟通教程。
  • 自建：npx prompts.chat new my-prompt-library 一键起一个私有库，安装向导配置品牌、主题、登录方式（GitHub / Google / Azure AD）。数据库是 PostgreSQL。
  • 集成：命令行 npx prompts.chat；MCP 服务器（远程或本地）；Claude Code 插件（提供 /prompts.chat:prompts 与 /prompts.chat:skills 两个斜杠命令，外加两个管理代理和自动触发的技能）。

注意事项

  • ⚠️ 推荐帖不是原创（推断）：演示视频右下角水印是 @silvanrec。本站在 X 上搜到 2026-10-21 22:51 UTC+8 @nikosolenne 的一条西班牙语帖，开头几句（“世界最大的提示词库、100% 免费、超过 173K 星、哈佛和哥伦比亚引用、兼容 ChatGPT/Claude/Gemini”）和本帖逐句对得上，配的视频也是 16.6 秒。Bitturing 的帖子很可能是那条帖子的中文转述，帖里没注明出处。Bitturing 简介自称“大自然的搬运工”。原始视频是不是 @silvanrec 做的，本站没查到原帖 ❓。
  • ⚠️ 投稿质量参差：任何人都能提交提示词，本站截图里最新几条就有测试性质、内容很少的投稿。用之前要自己筛。
  • ⚠️ 远程 MCP 会把查询发给第三方：README 推荐的远程 MCP 地址是 https://prompts.chat/api/mcp，你的搜索词会发到 prompts.chat 的服务器。介意的话用本地模式（npx -y prompts.chat mcp）或自建。本站没有调用这个接口。

🚀 自建

部署你自己的私有提示词库，可自定义品牌、主题和登录认证。

快速开始：

npx prompts.chat new my-prompt-library
cd my-prompt-library

手动安装：

git clone https://github.com/f/prompts.chat.git
cd prompts.chat
npm install && npm run setup

安装向导会配置品牌、主题、登录认证（GitHub / Google / Azure AD）和功能开关。

推荐数据库：prompts.chat 使用 PostgreSQL。如需托管数据库，我们推荐 Neon（README 中为推荐链接）。

赞助方：Neon

📖 插件文档

MCP 服务器：在你的 AI 工具里把 prompts.chat 当作 MCP 服务器使用。

远程（推荐）：

{
  "mcpServers": {
    "prompts.chat": {
      "url": "https://prompts.chat/api/mcp"
    }
  }
}

本地：

{
  "mcpServers": {
    "prompts.chat": {
      "command": "npx",
      "args": ["-y", "prompts.chat", "mcp"]
    }
  }
}
