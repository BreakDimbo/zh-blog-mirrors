ChrisHKAI-Video 是香港创作者 Chris（@ChrisHKAI）开源的视频 Skill：给 Codex 或 Claude Code 一条创作者的 X 链接，Agent 用代码把对方做成 3D 搪胶公仔短片——头像从主页「撕下」鼓成公仔，帖子立成墙，数字从页面升起。画面走 Blender Cycles 逐帧渲染，声音用 Python 合成或采样乐器；README 强调不用视频生成、不用图片生成、不用素材库画面。

它是什么

  • 形态：Skill creator-toy-intro + 本地渲染引擎依赖（Blender、Node、Python、ffmpeg、无头 Chrome 等）。
  • 输入：X 主页链接（或分享文案、截图）；先选 16:9（桌面页，推荐）或 9:16（手机页）。
  • 输出：默认约 30 秒、1920×1080 或 1080×1920、30 fps 的自我介绍片；可更长。另有成片、效果轨、平台封面等。
  • 方法：公仔按确认过的图用零件表/宠物套件/SDF 雕塑；主页 HTML + Blender 场景；声音六选一（含创作者原曲对拍）。不是填空模板——材料需要新动画时 Agent 可为该片写代码。
  • 成片示例（只链不转）：全部成片 · 蜗牛King / Kin / 铁柱AGI 等说明见 README。

怎样用与六步流程

Codex：克隆仓库后 python3 scripts/install-codex.py，在可写影片目录说 $creator-toy-intro Make a self-intro film for https://x.com/…。

Claude Code：claude plugin marketplace add … 再 claude plugin install chrishkai-video@chrishkai-video，或克隆后 --plugin-dir。

六步（每步停给你看）：0 检查电脑 → 1 链接与画幅 → 2 故事点与开场三选一 → 3 公仔转面确认 → 4 分镜+听声音签字 → 5 先试片再全质量渲染。分镜页会做节奏、碰撞净空、check/compare/sample 等检查；影片入账要求与已有片在六项里至少四项不同。

环境、声音与测试状态

  • 耗时与 token 都很大：研究+公仔+分镜签字后，Cycles 后台渲染常一小时以上（README：M4 Pro/M5 约 1.5 h）。high 可用，xhigh 更好。
  • 已测：Apple silicon + Claude Code（Opus/Sonnet 5.5）。Windows/Linux 未测；Intel Mac 跑不了 Blender 5.2。
  • ⚠️ Codex 完整成片效果尚未验证（仓库置顶警告）；欢迎在 Issues 回报。
  • 声音：bed/song/band/strings/fx/own；真实乐器约 1.4 GB，需确认后下载。

👋 关于我

我是 Chris（@ChrisHKAI），来自香港，在 X 上分享我用 AI 做的东西。

不是模板合集。 这里每一条片都是我和编程 agent 一起用代码做的。<br>

Skill 按 Claude Opus 5.5 调校，换了模型未必做得出来。

每条片的导演、制作、配乐和渲染，都由 agent 写代码完成：

  • 🧸 公仔：按你确认的图片，用零件表、宠物套件或有向距离场雕塑做出来
  • 🎨 画面：主页是 HTML，场景用 Blender Cycles 逐帧渲染
  • 🎵 声音：Python 合成、免费乐器采样演奏，或者把创作者自己的歌剪到影片的节拍上

不用视频生成，不用图片生成，不用素材库画面。头像、帖子和数字都是创作者自己的。

怎样用

按你使用的 agent 选择：Codex 或 Claude Code。两者共用同一份 Skill 和本地 Blender 引擎。

Codex（桌面版或 CLI）

克隆包含这次修改的仓库版本，再安装完整 Skill：

git clone --depth 1 https://github.com/ChrisHKAI/ChrisHKAI-Video.git
cd ChrisHKAI-Video
python3 scripts/install-codex.py

macOS/Linux 默认将 Skill 链接到 ~/.agents/skills/creator-toy-intro，因此请保留仓库文件夹。Windows 默认复制整个 Skill（如果 Python 命令是 python，请替换命令中的 python3）；macOS/Linux 也可以加 --copy 使用独立副本。安装器只需要 Python 3.9+，不会覆盖已有 Skill，也不会安装 Blender 等渲染依赖。加 --dry-run 可以先看安装计划；加 --skills-dir /path/to/.agents/skills 可以指定安装目录。

在 Codex 中打开一个可写的影片文件夹，然后输入：

$creator-toy-intro 帮我做一条自我介绍片：https://x.com/yourhandle

只在仓库内使用时，也可以直接用 Codex 打开这个仓库：随仓库提供的 .agents/skills/creator-toy-intro 链接会让它发现 Skill，无须用户级安装；影片放在仓库旁边的 my-films/ 中。两种发现方式选一种，避免列表里出现同名的两项。如果下载的 ZIP 没有保留仓库内的软链接，请运行安装器。没有看到 Skill 时重启 Codex。Codex 使用说明 包含路径、工具、图片检查和长时间渲染的处理方式。

请使用支持命令执行、图片查看和浏览器或搜索工具的本地 Codex 会话，下文的渲染依赖要求仍然适用。安装和离线检查通过不代表完成了 Codex 全流程成片测试，成片效果还需要实际验证。

链接安装的更新方式：在仓库中运行 git pull --ff-only。复制安装的更新方式：先将已安装的 creator-toy-intro 文件夹移到 skills 目录以外备份，更新仓库，再用 --copy 重新安装。卸载时只移除已安装的链接或 Skill 副本；影片工作区和共用渲染依赖可以保留。本安装方式依据 OpenAI 官方 Skills 文档。

Claude Code
方法一：安装 Skill（推荐）

在终端里：

claude plugin marketplace add https://github.com/ChrisHKAI/ChrisHKAI-Video.git
claude plugin install chrishkai-video@chrishkai-video

完整的 https:// 地址不需要 SSH key，下载约 2 MB。如果还是失败（连 GitHub 很慢或者连不上），就自己先下载，再加入那个文件夹：

git clone --depth 1 https://github.com/ChrisHKAI/ChrisHKAI-Video.git
claude plugin marketplace add ./ChrisHKAI-Video
claude plugin install chrishkai-video@chrishkai-video

之后在任何文件夹都能用。

  • 每条片有自己的工作区 <账号>-intro/，放在你启动时所在的文件夹。
  • Blender、Python 模块和无头 Chrome 装在用户级文件夹（~/Applications、~/.chrishkai-video、~/.cache/puppeteer），而且要你说好才装。
  • 其他 agent：把 skills/creator-toy-intro/ 整个文件夹复制到它的 skills 目录。
方法二：克隆仓库
git clone https://github.com/ChrisHKAI/ChrisHKAI-Video.git
mkdir my-films && cd my-films
claude --plugin-dir ../ChrisHKAI-Video

片放在 my-films/，不会进仓库。

然后直接说你想要什么

帮我做一条自我介绍片：https://x.com/yourhandle

幫我整條自我介紹片，主角係我個公仔：https://x.com/yourhandle

Make a self-intro film for https://x.com/yourhandle

链接、从 App 复制的分享文字、几张截图都可以。还没想好？Claude Code 输入 /chrishkai-video:creator-toy-intro，Codex 输入 $creator-toy-intro，它会问你要链接。

它用你的语言回答，开头只问一件事：16:9（X 电脑版主页，推荐）还是 9:16（X 手机版主页）。其他都从主页自己判断。

会发生什么

六步，每一步都停在一样你要看的东西上。

步骤做什么停下来等你的地方
0 · 电脑检查 Blender、Node、Python、ffmpeg 和 Chrome；你说一次好，就装齐缺的缺东西时的安装清单
1 · 你的链接读链接，开这条片的工作区16:9 还是 9:16
2 · 他的故事创作者最出名、最自豪的几件事，每件配上图片、数字（今天的数字，注明从哪里读到）和它会变成的动画；电脑装了 Grok Build 会先问你要不要用它搜 X（没装就直接用浏览器，不会问）公仔用哪张图做；然后一页选完：两三件故事、三款开场之一、收尾，每个选项都有预览图
3 · 公仔照原图的身体来做（人、动物、物件），用三种套件之一：零件表、宠物、雕塑一张转身图给你确认，颜色已经在深色舞台上检查过
4 · 分镜按你选的顺序排好每一段、节拍网格、真实的预览渲染、每种声音铺在动态分镜下面分镜页：在画面上留意见、选声音、签字确认
5 · 渲染先用最终画质渲染几秒样片，想先看的话有半尺寸快速版，然后是成片、只有音效的版本、各平台封面、最后检查成片

片子不是套模板：你的素材需要 Skill 还没有的动画时（比如插画拼成一个立体小世界、网页慢慢滚过），agent 会为你的片专门写出来。

你签字之前，分镜页会先帮你检查：

  • 节奏：冷场、公仔独自站太久或者小得看不见、头三秒，以及每行字停留的时间够不够读完。
  • 不会中途崩：check 在 Blender 开工前读一遍所有设定，用白话讲哪里错；分镜页全部通过、你签字之后，才开始正式渲染。
  • 颜色：每个字在深色舞台上都要看得清；配色取自创作者自己的图片。
  • 不穿模：公仔不会走进墙里、站进墙上凸出来的东西里，字条也不会穿过公仔。公仔会自己让开，clearance 在 Blender 开工前逐帧检查。
  • 要和通过的片一样好：compare 把你的片的开场、公仔出场、数字定格、高潮和结尾卡，和三条已经通过的片并排对比，agent 会把不够的地方改好。正式渲染之前，sample 先用最终画质连声音渲染最难的几秒。
  • 别又是上一条：交付过的片都记在台账里（Skill 自己的几条片一开始就在里面），新片在六样东西（开场、结构、招牌动作、配色、声音、结尾）里至少要有四样和每一条都不同。
  • 第二意见：另找一个全新的评审看简报和画面。意见不同时，只当多一个选择给你，不是规定。

故事选择现在先给出最多三条完整主线，并推荐一条：每条都有开场、 素材之间的关系、结尾和证据缺口。重要资料缺失时，再针对问题补搜一轮； 用 Grok 的话会再搜一轮。资料不足时会缩小故事范围， 不强行编出转折。旧项目仍可按原来的方式选择素材。

选好主线后，再做一次快速的内部文字故事测试：观众记住什么、为什么继续看、 换个名字还能不能成立，以及每个主要动作表达什么。它只是提醒，不会挡住片子， 不会多问你一次，也不会拖慢做公仔。实际动作有没有表达清楚，仍会在分镜和成片检查。

声音

用耳朵选：run.mjs listen 会把每种声音铺在动态分镜下面。

声音是什么
bed（默认）音效加一层很轻的长和弦
song模板完整的合成歌曲
band同一首歌，用真实乐器演奏
strings那层和弦换成真实弦乐组和钢琴
fx只有音效
own创作者自己的歌，对上影片的节拍

band 和 strings 需要乐器采样库，约 1.4 GB，你说好才下载。

开始之前
  • 要花时间，也很耗 token。 一条片要几个小时，不是几分钟：查资料、做公仔、签分镜，最后 Cycles 在后台渲染一个小时以上（M4 Pro、M5 约 1.5 小时）。high 思考强度可以用，xhigh 更好。
  • 在 Apple 芯片的 Mac 上测过，用的是 Claude Code 和 Claude Opus 5.5。Windows 和 Linux 还没测；Intel Mac 跑不了 Blender 5.2。
  • 需要 Blender 5.2+、Node 22+、Python 3.9+、ffmpeg 和无头 Chrome。Skill 会检查，你说好就装齐缺的；需要密码的那几样，由你自己贴进终端运行。如果连 node 都没有，先装 Node 22。
  • 每条片约 10 GB 空间，还要有 GPU：没有 GPU，Cycles 要渲染好几个小时。
  • agent 必须能看图片（每项检查都是一张图）和用浏览器查资料。
  • 可选：Grok Build 用来搜 X（每次搜索约 1–1.4 美元），以及真实乐器采样（约 1.4 GB）。
  • 输出：1920×1080 或 1080×1920，30 fps；默认 30 秒，内容多就更长。这一版只出 X；抖音、小红书、视频号、Instagram 之后每次更新加一个平台。
更新或卸载

更新，然后重启 Claude Code：

claude plugin marketplace update chrishkai-video && claude plugin update chrishkai-video@chrishkai-video

卸载：

claude plugin uninstall chrishkai-video@chrishkai-video

不需要的话，再删掉 ~/.chrishkai-video（Python 模块、字体、乐器采样和你的成片台账）。~/Applications 里的 Blender 和 ~/.cache/puppeteer 里的 Chrome 留不留由你。你的片的工作区不会动。

哪一步卡住了，请开一个 issue。

  • 真实乐器：采样器来自 lemo-opuscar，MIT 授权，放在 engine/vendor/lemo/。采样库保留各自的授权：CC0，只有 Salamander 三角钢琴（CC BY 3.0）和 MuldjordKit 鼓组（CC BY 4.0）例外。用到它们的片会生成一份 credits.txt，放进影片简介。
  • 不含字体文件：结尾卡用系统字体（兰亭黑、苹方、Helvetica Neue）或免费的思源黑体。系统字体用于商业用途，可能需要另外向字体厂商购买授权。

片里用的素材由你自己负责。
