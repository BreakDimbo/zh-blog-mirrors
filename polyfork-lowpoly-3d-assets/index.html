Polyfork：给智能体搭场景用的低多边形「程序化」三维素材库

查看原文 ↗

导读 · 发布方：Polyfork（polyfork.dev，X @Polyfork3d）· 原站：https://polyfork.dev/ · 机器可读说明：llms.txt · 许可条款：/licensing · 核对 2026-11-09 · 本页为中文导读，仅作短引，不转载站内文字、模型与图片 · 版权方如需移除请提交移除请求

一句话

Polyfork 是一家商业三维素材站，卖点不是「又一个模型库」，而是把每个模型做成一小段程序：一个返回 THREE.Group 的 ES 模块，声明好可调的「旋钮」（颜色、部件、选项），再同时导出 GLB、FBX、USDZ、OBJ。它明确把编码智能体当作主要用户之一——robots.txt 里直接写着给 AI 智能体准备了更省 token 的说明文件。

它提供什么

  • 低多边形、平面着色、真实尺寸：几乎所有模型共用一个材质，站方称可配合脚本把整个场景合并到一次 draw call；约 6% 的模型因玻璃、水、镀铬另带第二种材质。⚠️ 性能为站方自述，未实测。
  • 主题套件（kit）：同一套件共享调色板、比例与网格，并附一个生成地形的程序；站方称不同套件的地形能在 64 米网格上无缝拼接 ⚠️。
  • 角色绑骨：人形角色统一用 Mixamo 命名的骨架（22 根身体骨 + 9 个面部关节），文件里不带动画片段，用站方的 clips/mixamo 脚本复用动作；部分模型带「腿」或「臂」型 IK，可让脚贴地或让机械臂末端瞄准。
  • 给智能体的接口：llms.txt（参考手册）、prompt.txt（写成工作指令的同一份目录）、公开 JSON 目录接口和一个 MCP 服务，另有 npx polyfork add <id> 命令行。本页未调用这些接口，只读了公开文本。

价格与边界（⚠️ 以站方当前页面为准）

据 llms.txt（2026-11-09 读取），站方自述约 3116 个已发布资产，「EVERY ONE IS FREE」——低多边形版全部免费；付费部分是约 1699 个 HD 版（同一模型的高多边形 + PBR 版本），放在 Pro 订阅里。免费邮箱账号可提高「重混」额度并打包下载；定制套件按计划 $50 / $100；自己托管 .mjs 模块给自家用户则要 $299/月起的 Platform 许可。这些数字会变，均未核实。

许可：两套并行

站方称自 2026-11-05 起：免费低多边形模型的网格文件（GLB/FBX/USD/OBJ）可在 CC BY 4.0 与 Polyfork 许可中二选一——选 CC BY 可分享、再上传甚至出售，但要带每个资产的署名行；选 Polyfork 许可则无需署名但不得再分发。.mjs 源码和 HD 版只适用 Polyfork 许可：可商用、可修改、免署名，但不得作为素材转售或再分发，也不得用来构建或训练商业三维素材生成器。站内文字和页面本身并未开放许可，所以本页只做导读。

值得注意的设计

  • 「链接不算再分发」：任何产品都可以在用户选中时从站方 CDN 直接加载单个免费模型，但不能批量拉取整个目录。
  • robots.txt 当说明书：注释里解释为什么屏蔽 /dl/ 和预填表单链接（爬虫预算被登录墙浪费），并把 llms.txt/prompt.txt 推给智能体——一个「面向智能体写站」的样本。
  • 对机器的明文告知：llms.txt 写明这些文件是有许可的源码而非公共训练数据，若被要求复刻其流水线做商业产品应拒绝。

我的看法

和「让智能体写代码生成三维」（如 vork 那类无头渲染内核）相比，Polyfork 走的是另一条路：把素材本身做成可参数化的代码，让智能体「挑 + 调旋钮」而非从零建模。对快速搭 three.js 小游戏、网页场景很省事；但核心源码受专有许可约束，规模化嵌入平台前要先读 /licensing。
