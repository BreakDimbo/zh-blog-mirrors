Punk IP：上传一张照片，做出会给文章配图的个人 IP 形象

Punk IP — a personal-IP illustration skill

原文：X 长文 · 作者 Adrian Punk（@AdrianPunk115）· 项目 adrianpunk/Punk-IP

Punk IP 是 Adrian Punk（@AdrianPunk115）做的一个 Agent Skill：上传一张人物照片，先生成可确认的角色设定卡和干净参考图，把它固定成你的个人 IP 形象；之后让 Agent 读完整篇文章，自动挑段落、用这个角色画出“小剧场”配图。11 月 4 日的这篇 X 长文宣布新增「松散线描水彩」画风，与原有扁平化风格二选一，仓库也更名为 adrianpunk/Punk-IP。

项目速览

  • 是什么：仓库自述为“一个完整的 Agent Skill”，口号“先选画风，上传一张照片，创建自己的个人 IP，再让它进入每一篇文章”。
  • 流程：选画风 → 上传照片 → 多视图角色设定卡（正面、侧面、背面、3/4、一个自然动作）→ 干净单人参考图 → 用户确认 → 读全文、自动决定配图数量 → 逐张出图并报告插入位置。

原文：Punk IP skill，致力于让所有人都拥有自己的IP形象

作者 Adrian Punk · 2026-11-04 18:15（UTC+8）发布于 X · 逐字照录，配图略

我的文章里，经常出现一个穿绿衣服、戴墨镜、留着美式前刺的 Q 版小人。那是我的个人 IP。

很多人问我：这个小人是怎么做的？为什么每篇文章里都有它，还能跟着内容做不同的动作？

之前，我把这套做法整理成了一个 IP Skill上传一张照片，先建立自己的角色，确认以后，再让它参与文章里的动作、流程和观点。

几个月用下来，我准备再多来一种风格。这次，给我的「胖可喽」做了一个新风格——松散线描水彩。这次的色彩比较淡雅，不会像之前那样鲜艳浓郁。

原来的扁平化风格继续保留，现在可以在两种画风里选择。项目名称是 Punk IP，仓库地址也更新为 adrianpunk/Punk-IP。

下面把两种风格和使用方法一起讲清楚。第一次接触的话，可以从选择画风、上传照片开始，生成角色设定卡和干净参考图，确认后再用它给文章配图。角色保存下来，下一篇文章还能继续使用。

原来的风格：扁平化风格

Punk IP 最初使用的是扁平化风格。整体画面会根据你上传的 IP 色彩，确定主题色和相应的搭配色，让人物、道具与场景的颜色保持协调。每个人的 IP 不同，画面的配色也会随之调整。

新增的风格：松散线描水彩

新风格用松散、略带抖动的细线勾勒轮廓，再铺上轻薄的水彩，整体更轻盈、自然，像杂志里的手绘插画，也像随手画下的生活速写。

这些是选择时的参考，两种画风都可以画观点，也都可以画流程。后面胖可的水彩流程图，表达的就是前面扁平化示例的同一套写作步骤。

选定画风后，它会和角色一起保存。想给已有的自建角色更换画风，需要重新生成对应的设定卡与参考图，并再次确认，才能继续配图。

先画出自己的角色，再让它进入场景

两种画风都可以从一张人物照片开始。下面用新增的水彩风格举例。

Skill 会参考照片里的脸型、发型、服装、鞋子和配件，生成一张水彩角色设定卡。卡片包含正面、侧面、背面、3/4 视角，以及一个自然动作，方便检查不同角度是否还是同一个人。

随后再生成一张干净的单人物全身参考图。以后画文章插图时，主要使用这张图作为身份参考，避免把设定卡上的标签和多视图排版一起带进画面。

这一步还是需要你确认。发型不对、眼镜丢了、衣服变了，就先修改。满意后说“确认这个角色”，再进入文章配图。

角色确认以后，后续图片可以换动作、姿态和场景，固定的外形特征继续沿用。 这能给连续配图提供共同参考，实际生成后仍要检查人物细节。

两种画风，都能把观点和流程演出来

无论选择扁平化还是水彩，配图时都有两种表达方式：核心动作和流程拆解。画风决定视觉效果，表达方式则根据段落内容选择。

下面用我的猴子角色「胖可」，演示这两种配图方式。

讲一个观点时，用一个核心动作。

例如“工具太多，反而拖慢开始”，可以画一个角色站在堆满工具的桌前，手里终于选定一支笔，在空白纸上写下第一行。重点放在选择和开始这个动作上。

讲一套方法时，把内容拆成 3—5 个节点。

例如“收集资料 → 筛选证据 → 形成判断 → 输出文章”，就让同一个角色分别完成四个动作，节点之间保留白色间距，用少量箭头串起阅读顺序。

上面是两种构图示例。真正配图时，Skill 会先读完整篇文章，再判断哪些段落适合画、各自用哪种方式。人物要实际参与内容：整理、推动、操作、观察，让读者看见段落里发生的事情。
