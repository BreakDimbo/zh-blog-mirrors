dimensional-drawing：让 Agent 画出 Apple 式尺寸图

Apple-style dimensional drawings for UI components · 项目导读 + README 全文中译

一句话：dimensional-drawing 是一套给编程 Agent 用的 Skill。你指给它一个 UI 组件（源码文件、Storybook、网址或截图），它会画出一张像 Apple 配件尺寸图（dimensional drawings）那样的单页技术图：黑白线稿，边距、间距、圆角、图层和视口位置都用变量编号标注，表格里给出数值和公式。仓库里还有第二个 Skill，把画好的图纸做成约 10 秒的短片：像一支笔把图画出来，镜头在纸面上推拉。

项目是什么

Apple 给每台设备都公开一套尺寸图，方便配件厂商做出严丝合缝的保护壳。README 形容这种图“安静、密集、好看：一张纸，几个视图，几个小小的细节圈，到处是数字”。这个仓库就是教 Agent 用同样的方式去画你自己的组件：一张卡片、一个对话框，画成一张规格单，交给任何人都能照着复原它的结构。文案内容故意不画，这样文字改了，图依然成立。

仓库里有两个 Skill：

  • dimensional-drawing：画图。输出一个自包含的 HTML 文件（在 claude.ai 上就发布成 Artifact）。附两份完整样例：卡片 card-sheet.html 和对话框 dialog-sheet.html。
  • dimensional-drawing-motion：把画好的图纸做成约 10 秒的短片。主要目标是 Claude 的 Motion 制品，另有一个不依赖 Claude 的无头渲染器（Playwright 逐帧截图 + ffmpeg 编码）。

五条规矩

SKILL.md 给画图定了五条硬规矩，这也是它的图看起来“克制”的原因：

规矩具体做法
只用黑白灰白纸黑线，不许有任何强调色。靠线宽、虚线样式、剖面线和浅灰填充来区分元素。
画结构，不画内容UI 只画“插槽”：TITLE SLOT · FLEX、ACTION · HUG、CONTENT SLOT · FILL。不标文字宽度。HUG = 随内容，FLEX = 占剩余空间，FILL = 撑满父级。
用变量，不写死数字图上每个尺寸都是编号（S 间距、H 高度、R 圆角、E 阴影包络……），表格给出编号、变量名和数值；推导值写公式和结果，例如 H1 header-min = 2·S1 + H3 = 64、R2 r-inner = R1 − B − S6 = 11。
不带品牌图上、标题栏、页脚都不出现产品名或商标，除非用户要求；用中性名字，比如 UI-CARD-001。
不编数值源里没有的值一律写 [TBD]，按比例画示意。

它怎么量、怎么画

  • 量尺寸：读真实源码（仓库文件、Storybook、设计稿、网址），用 Playwright 渲染、等字体加载完，再遍历盒模型（getBoundingClientRect + getComputedStyle：padding、gap、圆角、边框、最小高度……）；还要用 grep 统计同类组件的所有用例，让变量反映的是整套设计系统，而不是某一个例子。
  • 版面：顶部是 HTML 标题栏（图号、版本、单位、比例、来源 + 通用注记 + 一排关键变量）；下面尽量只用一张 SVG 图纸：左上注记，中间平面图，左下分层爆炸轴测图，底部是嵌套圆角、各个圆角的细节视图，右栏是变量表。
  • 画图工具包：SKILL.md 给了一组 SVG 小函数（水平/垂直尺寸线、引线标注、圆角标注、注记编号框、细节圈、变量表），并规定了线宽、箭头、字号等细节。
  • 实物也能画：第三角投影的顶/前/右视图加剖面 A–A，单位毫米，只用公开发布的规格，列出来源，来源冲突标 CONFLICT，其余一律 [TBD]。README 的建议是“试试画一个保温杯”。
  • 交付前自检：图上每个编号都要在表里出现、每个公式都要闭合；不得有品牌文字和颜色（grep 灰度以外的色值）；按 1800 px 宽用 Playwright 渲染一次，看截图有没有标签重叠或越出图框，修一遍再交。

让图动起来

动效 Skill 把一张画好的图拍成“笔在画、镜头在动”的短片。参考片 11 秒，1920×1080、60 fps，分五拍：

  1. 0–2.3 秒：镜头贴近标题栏（约 4.4 倍），外框从左上角画起，接着是图标、标题插槽、分隔线和头部尺寸。
  2. 2.3–4.2 秒：拉远到平面图（约 1.7 倍），一边拉一边把剩下的部分画完。
  3. 4.2–7.2 秒：图层从平面“抬起”变成爆炸轴测图。先描边、后填充，否则白色填充会在线稿上闪一下。
  4. 7.2–9.2 秒：拉回整张图纸，注记、表格和细节视图依次画出。
  5. 9.2 秒以后：极慢的推镜，让最后一帧不死板。

关键设计是整个场景是时间的纯函数：render(t) 只根据 t 设定所有属性，不依赖上一帧，所以无头渲染器可以跳到任意一帧截图。缓动只用 ease-in-out / ease-out，不弹跳、不过冲、不加颜色，默认不加音乐和人声。

安装与使用

Claude Code：

git clone https://github.com/enesozturk/dimensional-drawing
cp -r dimensional-drawing/skills/* ~/.claude/skills/

其他 Agent（Codex、Cursor、Gemini CLI 等）：

npx skills add enesozturk/dimensional-drawing

然后直接说，例如：“给 src/components/Card.tsx 里的 Card 组件画一张尺寸图”“按样例的风格画出我们设置对话框的结构”。要做成短片就说“把这张图动起来”；不用 Claude 的话，到 skills/dimensional-drawing-motion/adapters/headless 下 npm install，再运行 node render.mjs --scene … --css … --out film.mp4（需要 Node 18+ 和 ffmpeg）。

dimensional-drawing ✏️📐

给它一个 UI 组件，还你一张单页技术图。
边距、间距、圆角、图层和视口位置，像 Apple 的尺寸图一样测量并标注。

安装 · 使用 · 让它动起来 · 样例

Apple 为每一台设备发布尺寸图，好让配件厂商做出合身的保护壳。这些图安静、密集、好看：一张纸，几个视图，几个小小的细节圈，到处是数字。

这个仓库教你的 Agent 用同样的方式画你的组件。一张卡片或一个对话框会变成一张规格单，交给任何人都能照着复原它的结构：边距、间距、圆角、图层、它在视口里的位置。文案和内容故意不画，这样文字变了，图依然成立。

使用

说你要一张图，并指向来源（仓库文件、Storybook story、网址、截图）：

给 src/components/Card.tsx 里的 Card 组件画一张尺寸图

画出我们设置对话框的结构，风格和样例一样

你会得到：顶部一个列出关键变量的标题栏，下面是一整张密集的图纸——注记、平面图、分层爆炸图、细节视图（嵌套圆角、各个圆角、主体），以及变量表。

实物也能画（第三角投影视图、毫米、只用公开规格）。试试画一个保温杯 🫖。

让它动起来 🎬

动效 Skill 把一张画好的图做成动画，就像一支笔在画它、同时一台摄影机在纸面上移动：

  1. 特写头部，它的线条一条条画出来
  2. 拉远到平面图，其余部分边拉边画
  3. 图层从平面图上抬起，变成爆炸视图（先描边、后填充，这样不会闪）
  4. 拉远到整张图纸，剩下的视图依次画出

场景是时间的纯函数，所以能在两个地方运行：

用 Claude说一句“把这张图动起来”。Claude 会在 Motion 制品里搭好它，你导出 MP4 即可。这是首选目标，节奏也是在这里调的。
不用 Claudecd skills/dimensional-drawing-motion/adapters/headless && npm install，然后 node render.mjs --scene ../../templates/scene-dialog.js --css ../../templates/base.css --out dialog.mp4。需要 Node 18+ 和 ffmpeg。

注意：针对 Claude Motion 优化。无头渲染器用 Playwright（Chromium）+ ffmpeg 测试过。其他动画库（Remotion、Motion Canvas、GSAP、Lottie……）没有测试。
