这是什么

motion-graphics-music-video 是 makevoid 发布的 Claude Code 插件：内含自包含的音乐视频 skill，以及从 P(doom)、wife/boyfriend 等成片工作流抽取出的 Ruby 工具包。

技术栈覆盖：

  • Fal：图像 / 视频 / 音频适配器（角色板、关键帧、H3 动画、转录、分轨、SFX 等）
  • p5：定时动效、镜头、文字与透明精灵合成
  • Python：节拍/能量分析、抠像、追踪、音频混合
  • Swift Core Image：按 cue 的最终 VFX（需 macOS）
  • RSpec：本地行为与模拟 Fal 集成测试（付费 live 测试需显式 opt-in）
准备一首歌 + 创意提示。Agent 先调研并写角色/场景计划请你审批，再按审核波次用子代理生成：2 → 3–4 → 4–8 → 6–10，反复直到成片。

默认可读焦点主体、有节奏的相机切换与「有意为之的混乱」动画；更安静的 brief 会覆盖该默认。病毒式传播是目标，不是承诺。

快速开始

安装命令保持上游英文原文：

claude plugin marketplace add makevoid/motion-graphics-music-video-skill
claude plugin install motion-graphics-music-video@makevoid-music-video --scope user
  1. 在终端启动 claude，配置 Fal 密钥： 
    /plugin configure motion-graphics-music-video
    在 Fal API key 字段填入你自己的 Fal AI 密钥（勿把真实密钥写进聊天或仓库）。
  2. 打开 Claude Desktop，选 Code，新建可访问文件夹的代码会话。
  3. 运行 skill，再提供歌曲与创意提示： 
    /motion-graphics-music-video:motion-graphics-music-video

插件的 music-video MCP 服务器用你的密钥跑所有 Fal 任务。Claude Code 把密钥放在安全凭据存储，只传给该服务器，会话本身看不到密钥。

更新插件

claude plugin marketplace update makevoid-music-video
claude plugin update motion-graphics-music-video@makevoid-music-video --scope user

更新后重启 Claude Code。已有视频工程保留各自拷贝的工具包；插件更新主要影响之后新初始化的项目。

用法与依赖

系统依赖

生成视频前安装：Ruby 3.2+（含 Bundler）、Node.js 22+、Python 3、Chrome、FFmpeg（含 ffprobe）、ImageMagick。Swift VFX 与完整测试套件需要 macOS 14+ 与 Swift 5.9+ / Xcode 命令行工具。

运行 skill

在 Claude Desktop Code 会话（有文件夹权限）或工作目录下的 claude 终端会话中调用：

/motion-graphics-music-video:motion-graphics-music-video

提供歌曲附件或本地路径，以及创意提示。Skill 会创建独立的视频项目，在该项目里跑 setup（装 Ruby gems、npm、本地 Python 环境）与 doctor（检查依赖）。在发起新的付费生成前，会请你审批计划与预算。依赖与成片文件留在视频项目内，不写回插件安装目录。

doctor 以 JSON 布尔值报告依赖检查结果。插件会话应通过 MCP 跑 doctor 以包含已配置密钥；直接 Bash 调用看不到插件的敏感选项。

本地开发 / 软链安装（可选）

git clone https://github.com/makevoid/motion-graphics-music-video-skill.git
cd motion-graphics-music-video-skill
claude plugin validate .claude-plugin/plugin.json --strict
claude plugin validate .claude-plugin/marketplace.json --strict

会话级加载：claude --plugin-dir /absolute/path/to/motion-graphics-music-video-skill。

跨项目手动软链（macOS / Linux，从仓库根目录）：

mkdir -p ~/.claude/skills
ln -s "$PWD/.claude/skills/motion-graphics-music-video" \
  ~/.claude/skills/motion-graphics-music-video

Fal API 密钥

说明：本镜像不会提供、编造或嵌入任何 API 密钥或价格数字。密钥由你在 Fal 账号自行申请，并通过插件配置或环境变量注入。旧的 FAL_KEY 与家目录密钥文件已不再使用。
  • 推荐：/plugin configure motion-graphics-music-video，填写敏感选项 FAL_AI_API_KEY。Claude Code 会遮罩并安全存储；插件经环境变量交给内置 Ruby MCP 服务器。
  • 选项为可选：未设置时服务器回退到启动 Claude Code 时 shell 中的 FAL_AI_API_KEY；两者皆无则 credential_status 报告 configured: false。
  • 独立开发时： 
    export FAL_AI_API_KEY='your-fal-api-key'
  • 切勿把真实密钥放进聊天、源码、命令参数或 git 提交。改密钥后重启 / 重连 MCP 服务器。

详见上游 credentials.md。

工作流与审核波次

执行契约：对 agent 与每个子代理，Ruby（scripts/mv.rb）是唯一媒体执行入口；不直接 curl Fal、不绕过 Ruby 调 FFmpeg / p5 / Swift。

  1. 接入与分析 — 收集歌曲与创意提示（可选：参考片、必须保留的角色、画幅、受众、预算）。默认 16:9、24fps、1080p。初始化独立项目 → setup → doctor → 本地节拍/能量分析；用网络搜索写 docs/RESEARCH.md。
  2. 计划并审批 — 写完整可审阅的 docs/PLAN.md（角色/场景提示、风格、成本粗估与重试额度等）。新方向须用户审批角色提示、场景提示与整体 vibe，审批前不做付费生成。批准后用 plan:approve 记录计划哈希。
  3. 分波次子代理生成 — 协调者拥有配置与终装；工人各自占用不同 RUN/资源。波次规模（资产任务数，不是帧数）：
    波次规模（上游约定）
    首波试点先 2 个资产
    随后3–4 → 4–8 → 6–10，并重复 6–10 直到完成
    每波结束后必须目视/听审、写 review、修理失败并用 work:accept 接受，才能进入下一波。开场与主高潮应尽早排进试点。
  4. 动画、合成与收尾 — H3 负责角色表演与口型；p5 负责图形/相机/文字；Python 负责抠像/分析/混音；Swift 负责最终 VFX。对照完整原曲拼接；交付成片、干净版、contact sheet、计划/调研、角色参考与修订摘要。完成 = 每个计划场景与结尾都已组装审阅，而不是只有开场试点。

两条历史路径（均不依赖旧项目文件）：P(doom) 偏参考片分析；wife/boyfriend 偏歌曲 + 创意提示 + 网络调研。

工具包命令

在仓库根目录（或已 init 的项目内）常用入口：

ruby .claude/skills/motion-graphics-music-video/scripts/mv.rb --help
ruby .claude/skills/motion-graphics-music-video/scripts/mv.rb setup
ruby .claude/skills/motion-graphics-music-video/scripts/mv.rb test

rake test 是对同一 Ruby 入口的薄封装。常规测试均为本地，不发起付费 Fal 调用。完整本地套件需要 macOS（Swift VFX）、Chrome、FFmpeg、ImageMagick、Node、Python 与 Ruby。仓库不捆绑原项目成片、歌曲、密钥或已生成角色；字体保留各自许可证文件。

插件侧：对 Fal 相关配方用 MCP 的 run_task / task_status（可并发至约 10 个本地 worker）；本地初始化、setup、计划审批与本地媒体任务仍走 Ruby CLI。

外部服务与数据共享（摘要）

  • Fal API 与存储（如 queue.fal.run、rest.alpha.fal.ai、提供商返回的 URL）：认证、提示词、歌词、设置，以及用于生成/转录/分轨的选定音视频。媒体 URL 可能被持有链接者访问；远端资产不会自动删除。参见 Fal 隐私政策。
  • Fal schemas：模型标识符查询。
  • 网络调研：创意简报搜索与参考 URL 会到达 Claude 配置的搜索提供商与访问站点。
  • 依赖与更新：setup 联系 RubyGems / npm / PyPI（或镜像）；插件安装更新联系 GitHub。
  • 本地处理：分析、渲染、剪辑与导出在本地完成。无维护者遥测、无自动社交发布。仍适用常规 Claude 对话与工具结果处理。
